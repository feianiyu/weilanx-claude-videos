# 老杨魔方竖版 · 对比结构（v2）

「老杨魔方 · 企业经营观察」的竖版知识解析动画：无旁白，靠视觉冲击讲清一个经营观点。
v1（一拍弹一行字、全程黑底绿光）已废弃：疏密、快慢、色彩都停在中间值，没有冲击。v2 的核心只有一句话——**冲击来自反差，不来自每一拍都在动**。

- 代码：`src/library/laoyang/`（`contrast.tsx` 对比组件、`brand.tsx` 品牌件、`theme.ts` 色板 / 字体 / 缓动、`stage.tsx` 颗粒与冲击波）
- 样片 / 模板：`ep52-laoyang-template`（35 秒，古德哈特定律示例）；封面 `ep52-laoyang-template-cover`（9:16）、`-cover-34`（3:4）
- 配乐：`node audio/episodes/ep52-laoyang-template.mjs`，纯代码合成，两遍 loudnorm 到 −15 LUFS
- 字体随仓库带：`public/fonts/laoyang/`（Noto Sans SC Black / Medium、Noto Serif SC Bold、Inter，GB2312 常用字子集，SIL OFL）

## 三组对比怎么排

| 段 | 疏密 | 快慢 | 色彩 | 示例 |
|---|---|---|---|---|
| 现实 | 极密：上万光点星云 + 漂浮关键词 | 极慢：差速旋转、心跳 | 低饱和灰绿 | 真实的经营，千头万绪 |
| 收缩 → 重拍 1 | 密 → 疏 | 加速，最后半拍静音 | 灰绿 → 金 | 星云旋成漩涡撞进一个数 |
| 一个数 | 极疏：全黑里一个巨大数字 | 慢：只剩一个钢琴音型 | 金 / 黑 | 98.7%，只看这一个数 |
| 失控 | 极密：36 格滚动数字 + 横切色带 | 极快：数字越跳越快、16 分踩镲 | 高饱和绿 | 数字疯长 |
| 退潮 | 密 → 灰 | 低通慢慢关上 | 绿 → 灰 | 可业务呢？ |
| 重拍 2 → 留白 | 极疏：一个词占半屏 | 定格 → 全部抽空 → 极慢浮现 | 反色：米白 + 深绿 | 指标一旦成了 / 目标 |
| 署名 | — | 短 | 浅底版署名 | 立方体 \| 老杨魔方 \| 企业经营观察 |

规则：
- 一屏只有一个视觉焦点；最重的那个词放在最安静的地方（留白 + 慢）。
- 快段之前必须有慢段，静音之前必须有满编；两次重拍都在小节线上。
- 版式用编辑式左对齐（x = 100），大小反差拉到 10 倍以上（400 号大字 vs 26 号小字）。
- 反色用圆形擦除（屏幕覆盖面积随时间线性增长），不闪白；相邻帧平均亮度跳变 < 20（样片最大 8.6）。
- 品牌：深色段左上角标 + 底部脉动立方体（亮绿）；浅色段按看板换深绿 logo + 浅底版署名；格子段收起底部 logo。

## 组件速查（`contrast.tsx`）

| 组件 | 用途 |
|---|---|
| `Nebula` / `NebulaWords` | 星云和漂在里面的小字；`contract` 0–1 整体旋进 `target` 矩形 |
| `ConvergeStreaks` | 数字周围缓慢往里流的金色细线 |
| `BigNumber` | 巨大数字（编辑式左对齐），砸下 + 呼吸光；`jitter` 抖动 + 红绿色散；位数多时自动缩小 |
| `KpiGrid` | 36 格滚动数字，越跳越快、一路涨过 100；`grayAt` 起从底部逐行退潮变灰并停住 |
| `SlamBand` | 横切实心色带，文字从右侧甩入替换；`grayAt` 起变灰 |
| `CircleWipe` | 圆形擦除换底（反色） |
| `FallingDots` | 浅底上飘落的灰点 |
| `SlowText` / `Rule` | 慢速浮现的一行字（模糊 + 宽字距收拢）/ 从左画出的细线 + 色块 |
| `CanvasLayer` | 通用 canvas 图层（每帧重画，纯函数） |

## 换题步骤

1. 复制 `src/episodes/ep52-laoyang-template/` 和 `audio/episodes/ep52-laoyang-template.mjs`，改成新期号
2. 先按老杨魔方流程定内容、定逐秒脚本（时间 | 屏幕文字 | 画面 | 音乐），确认后再动代码
3. 改 `timeline.ts`：文案、`T` 里的拍号、`KICK_BEATS`；音频脚本顶部的段落表改成同样的拍号
4. 每期换一种「展示方式」，但保留至少两组对比；自创框架、举例画面标「示意」
5. `node audio/episodes/<期>.mjs` → Studio 预览 → `npx remotion still` 抽帧检查重拍前后 → 在 `src/Root.tsx` 的「10-老杨魔方竖版」里注册
