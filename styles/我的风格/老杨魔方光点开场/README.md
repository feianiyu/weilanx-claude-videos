# 老杨魔方 · 光点开场

「老杨魔方 · 企业经营观察」的竖版短片风格：**一颗光点贯穿全片**，每次变形就"长"出一个新容器（光盘 → 光环 → 星芒 → 胶囊 / 卡片 → 点阵 → 白闪 → 绳线胶囊 → 描边框 → 雾团 → 立方体 logo），每个容器里只放一句 2–7 个字的细体中文，整条文字链读下来是一句完整的话。无旁白，配乐纯代码合成。

- 代码：`src/library/glowline/`（动效库，每个效果的"换场景演法"写在它的 README 里）
- 样片：`ep53-laoyang-visible`（32.9 秒，「让知识可见，让思想有形」）；封面 `ep53-laoyang-visible-cover`
- 配乐：`python3 audio/episodes/ep53-laoyang-visible.py`（numpy + scipy + ffmpeg），两遍 loudnorm，约 −16 LUFS、峰值 ≤ −3 dBFS

## 节奏骨架（ep53 实测，可整段套用）

| 段 | 时间 | 底色 | 容器 | 声音 |
|---|---|---|---|---|
| 起 | 0–1.67 | 黑 | 光点升起、光盘 | 低沉铺底 + 上升噪声 |
| 切 1 | 1.667 | 青光满屏 | 冲刷光带 | **低频重击 1** |
| 立 | 2.36–5.0 | 黑 | 光环 + 玻璃透镜文字 → 四角星 → 星芒 | 分裂四声高音、故障声、5.0 长鸣 |
| 展 | 5.0–9.15 | 黑 | 星芒 → 胶囊 → 渐变卡片甩出 | 7.36 闷击 |
| 串 | 9.15–14.47 | 黑 | 弹跳串 5 点 → 起伏 → 柱线上摇 | 5 声上行拨弦、弱律动、上升音 |
| 切 2 | 14.47 | 白闪 | 光点胀成白圆 | **低频重击 2**，和声转亮 |
| 承 | 14.47–22.37 | 白 | 绳线串三颗胶囊 | 三声逐级升高的铃 |
| 切 3 | 22.367 | 青光擦回黑 | 径向擦除 | **低频重击 3** |
| 合 | 22.37–25.3 | 黑 | 描边框 + 打字 | 上滑音、打字声 |
| 点题 | 25.3–29.42 | 黑 | 雾团 + 两行大字 | 每个词一声铃 |
| 落版 | 29.42–32.9 | 黑 | 立方体 logo | 长铃和弦，淡出 |

规则：
- **三次底色切换就是三次重击**，切点只有一帧亮度跳变；其余时间相邻帧亮度差 < 20。
- 一屏一个焦点、一句话；中文细体（LY Sans 300 / 400），比同位置英文大 20% 左右。
- 色彩只用电光蓝、青、青绿、品红四色 + 黑 / 白底；品牌亮绿只给结尾 logo（深底），浅底用深绿。
- 底部常驻一行「老杨魔方 · 企业经营观察」逐字加粗扫光（白闪起出现，深浅底自动换色）；片尾只做一件事：logo +「关注老杨魔方」。

## 换题步骤

1. 先按老杨魔方流程定内容、出逐秒脚本（时间 | 屏幕文字 | 画面 | 音乐），确认后再动代码。
2. 复制 `src/episodes/ep53-laoyang-visible/` 和 `audio/episodes/ep53-laoyang-visible.py`，改成新期号；新期号取 `src/episodes/` 最大号 + 1。
3. 只改 `timeline.ts` 的 `TEXT` 就能换一套文案；要改节奏，同时改 `timeline.ts` 的 `HITS` / `SHOTS`、`scenes.ts` 里对应段落的关键帧、配乐脚本顶部的 `HITS`（测试会比对两边是否一致）。
4. 想换"演法"，到 `src/library/glowline/README.md` 挑每个效果的替代演法；每期至少换掉一段容器，避免和上一期一模一样。
5. 生成配乐 → Studio 预览 → `npx remotion still src/index.ts <期> out.jpg --frame=N` 抽查三个切点前后 → 在 `src/Root.tsx` 的「10-老杨魔方竖版」里注册 → `npm test`、`npm run typecheck`。
