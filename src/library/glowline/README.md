# 光点开场 `glowline/`

一颗光点贯穿全片的竖版动效库：光点升起拉出光盘 → 分裂成光环、文字在玻璃透镜里折射 → 收成星芒钻进胶囊、撑成渐变卡片 → 弹跳串起一排点、长成柱线 → 胀成白闪 → 白底上一根绳线串起黑胶囊 → 黑底画出描边框打字 → 雾团托着两行大字 → 立方体 logo 落版。

- 样片：`ep53-laoyang-visible`（32.9 秒，「让知识可见，让思想有形」），配方卡见 `styles/我的风格/老杨魔方光点开场/README.md`
- 技术：canvas 2D，**一切是时间 t（秒）的纯函数**；在 Remotion 里用 `GlowCanvas` 逐帧画，帧号 → `t = f / fps`
- 色板 `GC`：电光蓝 `#2433ff`、青 `#19f0ff`、青绿 `#1fe3b5`、品红 `#d832ff`；品牌亮绿 `#2BE08A` 只给 logo
- 字体：`LY Sans` 300 / 400（本目录 `fonts.ts` 注册，思源黑体 Light / Regular 子集）+ laoyang 的 500 / 900。中文细体要比同位置英文大 20% 左右

## 三步接进一期

```tsx
import {GlowCanvas} from '../../library/glowline/GlowCanvas';
import {clearFrame, kf, seg, CX, CY} from '../../library/glowline/core';
import {ringStar, lensText} from '../../library/glowline/effects';

const render = (t: number) => {
  clearFrame('#000');
  const S = kf(t, [[0.5, 4], [0.7, 380], [1.5, 470]]); // 1. 用 kf / seg 编排时间
  ringStar({S, e: 1, rot: 0, spin: 0.8 * t, glowA: 1, lineA: 1}); // 2. 调动效
  lensText({text: '以体系思考', R: S * 0.93, D: kf(t, [[0.6, 1], [1.4, 0]]), clearR: kf(t, [[0.9, 0], [1.4, 520]])});
};
<GlowCanvas f={frame} fps={30} render={render} />; // 3. 放进画面
```

时间编排的约定：入场用 `eo3`（快进慢停），甩出用 `ei2`（慢起快走），镜头用 `kfSmooth`（速度连续）。一屏一个焦点；切换点（冲刷、白闪、硬切）对准配乐重击，三颗胶囊的碰撞对准三声逐级升高的铃。

## 招牌动效与换场景演法

每个效果都写了三件事：**怎么调**、**ep53 怎么用的**、**换个场景还能怎么演**。换场景时只换"讲的是什么"，动作的骨架（起势 → 高潮 → 收）保留。

### 1. 光盘 `glowDisc(x, y, w, a)`
一只发光的椭圆托盘（上蓝下青，底边一道白光）。
- ep53：开场光点上升时，在它下方每隔 0.2 秒生出一只，向下推进变大；结尾整串收拢（宽度 × 0.5）像镜头拉远。
- 换演法：**层级 / 楼层**——一摞光盘自下而上点亮，讲"组织层级""能力阶梯"；**涟漪**——同一位置连续生出、只变大不移动，讲"影响扩散"；**入口**——镜头穿过一只放大到满屏的光盘转场。

### 2. 冲刷 `topVeil(h)` + `washBand(top)`
先是顶部一层蓝光缓缓压下（蓄势），再一刀切成满屏青光，青绿 → 青 → 蓝的光带向下扫出。
- ep53：1.667 秒，配合第一声低频重击。
- 换演法：**换章**——每章开头都用一次，颜色换成本章主色；**揭晓**——光带扫过后露出答案（答案提前画在光带下层）；**倒放**——光带从下往上收回 = "回到起点"。

### 3. 光环 `ringStar({S, e, rot, spin, glowA, lineA})` + `ringNodes`
超椭圆描边 + 青 / 蓝交替的锥形渐变光晕。`e`：1 圆 → 2 菱形 → 2.7 内凹四角星 → 再回到 1.6 圆角方；`spin` 让光晕绕圈流动。
- ep53：光点分成 4 个节点 → 扩成光环 → 光环变内凹四角星、旋转 → 缩成小星芒。
- 换演法：**框架成形**——圆（混沌）拉成方（结构），讲"从想法到方法"；**收敛**——多个光环同心套叠、依次缩进一个点；**四象限**——四角星的四个尖各挂一个词（`superPoint` 取尖点坐标）。

### 4. 玻璃透镜 `lensText({text, R, D, clearR})`
文字在玻璃球里折射，边缘镜像拉伸、带红蓝色散；`clearR` 从 0 涨到超过 `R`，清晰区从中心向外化开。
- ep53：「以体系思考」在光环里 0.8 秒从扭曲到清晰。
- 换演法：**看清本质**——先扭曲后清晰（本期）；**认知偏差**——反过来，清晰的字被慢慢扭曲；**放大镜**——`R` 小、在一行长句上平移，只放大关键词。逐像素计算较慢，只在 `D > 0` 的十几帧调用。

### 5. 膨胀白闪 `inflateFlash(cx, cy, r, haloA)` / 径向擦除 `radialWipe`
一个光点胀成带色散边（上品红、左下青、右蓝）的巨大白圆，0.1 秒盖满全屏 = 黑底切白底；反方向用 `radialWipe`（一团青光长满屏后硬切黑底）。
- ep53：14.47 秒白闪进白底段，22.37 秒青光擦回黑底。
- 换演法：**顿悟**——任意一个小点（数据点、人物头顶）胀开进入"答案世界"；**反转**——白底段讲"表面"，黑底段讲"真相"；注意相邻帧亮度跳变只在切点那一帧，不要连续闪。

### 6. 渐变胶囊 → 卡片 `morphPill(..., stage)` + `gradientCard`
胶囊白 → 淡紫青 → 深蓝到青，三段 alpha 由调用方给；随后撑成左下暗、右上亮的大卡片。
- ep53：星芒落进白胶囊，0.7 秒变色撑开成「结构 / 决定焦点」卡片，再倾斜带残影甩出。
- 换演法：**按钮被按下**——胶囊 = 一个选择，变色 = 做了决定；**标签升级**——小标签撑成定义卡（术语 → 解释）；**卡片流**——连续几张卡从同一胶囊撑开、依次甩向不同方向。

### 7. 彗尾 `cometTrail(pos, t, {tStart, tEnd})`
一个点沿轨迹运动时身后拖出的渐变粗线（头青、中蓝、尾品红）。`pos(t)` 是任意轨迹函数。
- ep53：光点从右往左弹跳 4 次，每落一下点亮一个点。
- 换演法：**串联要素**——弹到哪个点哪个点亮（本期）；**路径 / 流程**——沿一条曲线跑完一遍流程图；**轨迹对比**——两条不同颜色的彗尾讲两种做法。

### 8. 绳线串胶囊 `stringLine` + `capsule` + `bump`
白底上一根带点头的灰线游走（`buildTimedPath` 写路标 + `pathUntil` 画到线头），碰到黑胶囊时从接触点扩散一团色光、胶囊回弹；镜头用 `kfSmooth` 跟着线头走。
- ep53：「搭建框架 → 创造节奏 → 塑造意义」，品红 / 电光蓝 / 青绿三次碰撞，各配一声逐级升高的铃。
- 换演法：**步骤串讲**——3–5 步方法论（本期）；**因果链**——每颗胶囊是一个原因，线是传导；**时间线**——胶囊换成年份，线一路穿过；颜色按"情绪"排：冷 → 暖或暗 → 亮。

### 9. 描边轨迹 `makeTrack` / `roundedFrameTrack` + `drawTrack` + `typeOn`
一个点画出一条带蓝 → 青绿发光的线（引线只跟着点头一小截），画完后右侧渐隐；框里逐字打出。
- ep53：黑底上画出圆角框、打出「融会贯通」，再斜切模糊甩出。
- 换演法：**圈重点**——绕一个已有的词画框；**签名 / 定稿**——画一条下划线后打出结论；**连接**——`makeTrack` 传任意折线，把两个元素连起来。

### 10. 雾团 `blobCluster(t, {center, spread, A, grow})`
几团饱和色光（蓝、品红、青、深蓝）绕中心转，`center` 跟着最新出现的词走；`spread` 先聚后散，结尾胀大淡出。用 `source-over` 叠，颜色饱满不发白。
- ep53：托着「让知识 可见 / 让思想 有形」，最后汇到中心、炸开，露出 logo。
- 换演法：**思想在流动**——词出现在哪雾团就飘到哪（本期）；**情绪温度**——换成暖色组讲"热度"、冷色组讲"冷静"；**聚合**——多团从屏幕四角汇到一个词背后。要更强的粒子张力，换用 `mist/ColorMist`。

### 11. logo 显形 `logoReveal(t, t0)`
立方体先以蓝青紫玻璃渐变弹出（0.55 → 1.07 → 1），再亮成品牌亮绿并带外发光，约 0.56 秒完成。
- ep53：29.42 秒，从炸开的雾团中心出现，下方「关注老杨魔方」。
- 换演法：任何深底片尾都能直接用；浅底改 `color: GC.greenDeep, glow: 0`。按看板要求低调：可以把 `size` 降到 120、`y` 放到画面下方。

### 12. 逐字加粗扫光 `boldSweep(text, cx, y, size, t, t0)`
底部一行小字，一个"粗体高光"从左往右扫过，扫完停顿再来。
- ep53：「老杨魔方 · 企业经营观察」从白闪起常驻底部，深浅底自动换色。
- 换演法：系列名 / 期号 / 出处小字（引用他人观点时放出处）都可以用这条，比静态小字更有"活着"的感觉。

## 注意

- 每个函数只画"这一帧"，不要在里面读真实时间或随机数；需要随机用 `laoyang` 的 `rand(seed)`。
- `lensText` 和大半径 `blur` 较慢，Studio 预览卡顿时先看 `npx remotion still`。
- 白闪、硬切前后用 `signalstats` 查相邻帧亮度：只允许切点那一帧跳变，其余 < 20。
- 视觉语言参考了一类"光点串联式"动态设计开场；组件全部重写，示例文案自编，不含任何原片的文案、标识和帧。
