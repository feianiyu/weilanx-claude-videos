# 枯寂与繁花（老杨魔方 · 治愈系，40 秒，无旁白）

一棵植物从干枯的枝骨开始：根在地下发着微光往深处长 → 树液的光沿枝条上行，枯枝转绿 → 新枝抽出、越长越快 → 24 秒繁花从花冠中心向外炸开（约一万朵五瓣小花，奶白 → 粉 → 淡紫）→ 30 秒后颜色向蓝紫漂移 → 镜头推进，花铺满整屏。

- `bloom.js`：画面是时间的纯函数；枝、根、花的结构由固定种子在加载时生成，每段枝条有自己的出生时间和生长时长。
- `music.py`：钢琴（加法合成）+ 弦乐铺底 + 细碎铃音，D 大调，−14 LUFS → `music.wav`
- 渲染：`for i in 0 1 2 3; do python3 brender.py frames $i 4 & done; wait`，再用 ffmpeg 合成 `bframes/` 和 `music.wav`。
- 参考：用户提供的一支「细茎长出满天星」的参考视频，借了「黑底、细线、密花、颜色慢慢漂移」的语法，结构和内容都是重写的。
