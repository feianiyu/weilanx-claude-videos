# 小黑闯江湖 · 参考实现（第 1 回导演版样片）

竖版 1080×1920 / 30fps，画面 = 时间 t 的纯函数（Canvas 2D）。

- `timing.js`：全片唯一时间表（各镜头起止、配音每句的起点和时长、关键事件时刻）。先有配音，再按配音时长排时间表。
- `xh2.js`：角色 `ball()`（黑色橡胶球 + 发光眼 + 四层光）、`hop()`（弹跳与压扁拉伸）、布景（雨夜城市、天亮城市、房间）、7 个镜头函数 `shot1…shot7`、转场（叠化、穿屏、光圈、甩镜）。
- `render2.py`：`python3 render2.py test 1,5,9` 抽帧；`python3 render2.py frames <分片> <分片数>` 渲染。
- `audio2.py`：配乐（八音盒 / 钢琴 / 弦乐）、雨声、音效、配音混音（说话时音乐自动让位），两遍 loudnorm 到 −14 LUFS。

不在仓库：片名字体 ZCOOL QingKe HuangYou（OFL）、配音文件。
