# 老杨魔方 · 知识分享版（有旁白）

全部规则在 `laoyang/knowledge-video/STANDARD.md`（当前 v2.0），开工前必读；同时读 `CHANGELOG.md` 最近两版、`BACKLOG.md` 前 5 条、`EFFECTS.md` 里状态为「标准」的效果。迭代制度见 `ITERATION.md`。

## 流程（不可跳步）
1. **内容**：核心观点一句话 + 骨架（钩子数字 → 背景事实 → 现场变化 → 作者观察 → 收一拍后「我的判断」→ 二选一提问 → 关注老杨魔方）；事实逐条核一手来源写 FACTS.md，未核实的不用。等用户确认。
2. **文案**：逐句 v01…vNN，标出章节、收一拍位置、核心观点句和它的文字出场方式（STANDARD §5.2）。等用户确认，确认后一字不改。画面和配音去人名、公司名。
3. **制作**：`cp -r starter episodes/<日期_主题>` → 改 lines.json / scenes.html / scenes.js → `fake_vo` 先排版 → `gen_vo` 真配音 → `fetch_assets` → `beatfit` 测拍 → `build` → `qc`（自己看联系表）→ `render final` → `qc --video` → `cover`。命令见 STANDARD §7。
4. **交付**：成片、封面、发布文案（标题 ×2、一句话正文、置顶互动提问、标签）、源码 zip（不含底图 / BGM / 音效）。
5. **收尾（迭代制度）**：写 `episodes/<期>/复盘.md`（模板 templates/复盘.md），把用户每条反馈分成本期 / 通用 / 偏好；通用的改写成可检查的规则落到 STANDARD / EFFECTS / core；改了 core 必跑 `python3 core/regress.py`（有意改画面用 `--update` 并写 CHANGELOG）；升版本号并同步技能和项目文档；开 PR。每做完 3 期做一次阶段复盘（ITERATION §5）。

## 硬规则
- **v2 版式**：不写眉标和卡片标题；每章的观点写进 lines.json `heads`，显示为顶部「核心观点头条」（≤2 行、每行 ≤9 字，写观点不写章节名，不与中间区同时重复）。中间区 x160–920 / y600–1380 全部用于动画；字号上限 96px，中间区核心观点 64–88px、≤2 行。
- 画面跟配音的词走：锚点 `T('v05|下降|s')`；三档速度（漂 / 推 / 击）每章至少两档；同一时刻只亮一种彩色。
- 文字效果一期只选 2–3 种，只给核心观点，每章最多一处；碎裂只落在击拍上。
- 每个实数注来源，示意图注「示意」；音效 ≤20 个；响度 −14 LUFS。
- 新能力默认关闭、按需打开；规划院 V2.3 必须一直能原样渲染（回归测试守着）。
- 无法真正试听：请用户戴耳机听音效和多音字，手机上看细粒子是否被压缩糊掉。
