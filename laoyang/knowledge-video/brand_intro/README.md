# 老杨魔方 · 电影感品牌片头（v1，2026-11-27）

4 秒竖屏 1080×1920：AI 镜头（Flowith · 可灵 3.0 Pro 文生视频，光粒汇聚 → 中心闪光）+ 代码精确定版 logo + 按节拍合成的音效。

- 节奏（100 BPM）：0.6 / 1.2 / 1.8s 三拍机械拧动 → 2.05 / 2.22s 加速 → 2.36s 抽空 40ms → **2.4s 闪光重击、logo 回弹落定** → 2.75s「老杨魔方」→ 3.0s「企业经营观察」→ 3.15s 金线 + 闪音 → 3.3–3.8s 光扫 logo。
- 画面：AI 镜头降饱和、压黑、偏绿；闪光 + 横向变形光条 + 轻震；全程缓推 6%；胶片颗粒、暗角。
- logo、字标、配色都按品牌看板（`L_*.png` 由 `layers.html` 渲染，几何与 build.py 的 `CUBE` 一致）。
- 响度 −14 LUFS 左右，真峰值 −1.5 dBFS。

```bash
python3 compose.py <AI 镜头.mp4> <镜头里闪光峰值秒数> <输出.mp4>
# v1：python3 compose.py laoyang_intro_particles.mp4 4.55 out.mp4
```
