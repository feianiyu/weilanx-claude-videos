## v2（2026-11-27，当前方案）：碎片 → 金属魔方世界 → 冲进光隙 → 溶进正片
老杨要求：不展示 logo 和文字；要电影画面感、立体的好莱坞式音效、短而有节奏；和正片无缝衔接。
- 画面：Flowith · 可灵 3.0 Pro 两段文生视频（9:16、5s、开音频），按 80 BPM 剪：0–0.75s 碎片高速掠过（1.6 倍速）→ 0.75–2.25s 拼合咬合、缝隙亮起琥珀光 → 2.25–3.9s 魔方逼近、镜头冲进缝隙、满屏暖金雾；3.6s 起 0.5s 溶进正片第一张钩子卡（正片是暖琥珀调，金雾正好接上）。
- 调色：降饱和、提反差、偏暖琥珀、暗角、颗粒，和正片底图一致。
- 声音：镜头自带的同步音效（碎片呼啸、金属咬合、穿越风声）为主；叠开场低频隆隆、反向吸气、两记低频重击（0.75 / 2.25s）、冲入时一记重击、用镜头自身声音做的混响尾。无旋律、无电子叮当。−14 LUFS。
- 源镜头（老杨 Mac ~/Downloads）：laoyang_introA_assemble.mp4（碎片拼成魔方）、laoyang_introB_dive.mp4（冲进缝隙）。提示词见下。
```bash
python3 edit_v2.py A.mp4 B.mp4 out.mp4                                  # 只出片头
python3 edit_v2.py A.mp4 B.mp4 正片开头.mp4 正片开头.wav out.mp4          # 片头 + 溶进正片的预览
```

## v1（已弃用）：光粒汇聚 + logo 定版（compose.py）——老杨不要 logo、音效太廉价

4 秒竖屏 1080×1920：AI 镜头（Flowith · 可灵 3.0 Pro 文生视频，光粒汇聚 → 中心闪光）+ 代码精确定版 logo + 按节拍合成的音效。

- logo、字标、配色都按品牌看板（`L_*.png` 由 `layers.html` 渲染，几何与 build.py 的 `CUBE` 一致）。
