# 深度长视频 v1（5 分钟以上）

2026-11-20 起。来源：老杨看 EP.29《祝波善：设计行业不是过冬是换季》（7 分 38 秒，第一条深度长视频）后的四条意见：

1. 开场的语速比后面慢；
2. 前 10 秒太慢，没有一上来就说清「谁、写了什么、核心观点」；
3. 开场动画不够抓人；
4. 7 分钟可以，但要想办法让人看完，不能沉闷。

本标准**叠加**在 `STANDARD_RETENTION_SCRIPT.md`（留存六拍 v1.2）和 `STANDARD_DEEP_V3` / `V7` 之上。只要估算时长超过 300 秒，`core/lint_retention.py` 就按这里再查一遍（都是提示，不拦出片）。

## 1. 语速统一（自动）

- 配音按气口组合成，每组的语气提示不一样：`hook`、`heavy`（一句一顿）、`num`（数字放慢）这类演法会把句子拖慢，开场往往最慢。EP.29 实测：开场 4.5–5.2 字/秒，正文中位约 6 字/秒。
- 出片机在「配音」之后多一步 **语速统一**（`core/pace.py`）：
  - 算每句「字 / 秒」（按真正出声的时长），取全片中位数 M；
  - 比 0.9×M 慢的句子，不变调提速到 0.97×M，单句最多 1.15 倍；
  - **开场 20 秒内**不允许比 M 慢，最多提 1.25 倍；
  - 不动：本质句、`emo` 里写了「放慢 / 一字一顿 / 留白」的句子、单句写了 `"pace": false` 的句子。
- 出片报告里多一行「语速」：中位语速、开场语速、提速了哪几句。
- 想关掉：`lines.json` 写 `"pace": {"on": false}`；参数见 `core/pace.py` 文件头。

## 2. 开场 10 秒：直给

解读一个人、一篇文章、一份报告时，**第一句就说清谁、做了什么，第二句给核心观点**，不要先铺垫观众的痛点：

> 天强公司创始人祝波善先生，最近写了一篇文章。
> 核心就一句话：工程设计行业不是在「过冬」，而是在「换季」。

然后：
- **第 3 句**用一句话解释核心观点（过冬 vs 换季）；
- **第 4 句**给全片地图：「这期用 7 分钟讲清四件事：……」，时长和章数都说出来；
- **第 5 句**说清和观众的关系：「如果你的企业……，接下来这四件事都和你有关」。

`lines.json` 写 `"source": {"who": "祝波善", "org": "天强公司创始人"}`，体检会查前两句有没有点出这个人。人物的身份按老杨给的写法（例：祝波善 = 天强公司创始人）。

开场 20 秒内不要用「一顿 / 放慢 / 留白」这类语气；短句（< 8 字）并到相邻句里。

## 3. 开场画面

- 0 秒：`hook` 卡，身份小标 + 名字砸出来，名字一念完就出第二行（「最近写了一篇文章」），前 5 秒画面至少动两次。
- 核心观点那一句：单独一张 `fxtext` 卡（`rel: "核心观点"`），**粒子聚拢成字、说完碎裂**。整句 ≤ 3 行、每行 ≤ 12 字。
- 长片打开暖色烟带：`"fx": {"mist": 0.5}`（hook / 金句 / 文字出场卡会有一次炸开），给 7 分钟一点呼吸感。

## 4. 章节结构：让人知道还剩多少

- 5–8 分钟分 **3–5 章**。每章第一句用「第 N 件事：……？」开头，配一张 `fxtext` 章节卡（`rel: "章节"`，`morph: false`），入场在「光扫」和「粒子」之间交替，退场「雾散」。
- 开场第 4 句报过的章数，章节卡必须一一对上。
- **每章最后一句钩下一章**：预告或问句，例「这个问题，他用了三年来回答，下一部分就讲他怎么想的」「还有一件事也在变，而且变得更快」「最后一件事最关键」。章与章之间是最容易流失的地方。
- 每章里至少一个数字或一张逻辑图换场；四句以上平铺就插一个问句、转折或数字。

## 5. 结尾

- 本质句尽量放在 55%–85%；如果原稿把它放在最后一段，至少在中段先用一张卡预告一次。
- 最后一句是选择题（留存 v1.2）：「A……B……C……，评论区打字母」。

## 6. 体检（`lint_retention.py`，时长 > 300 秒才查）

| 查什么 | 提示 |
|---|---|
| `source.who` 不在前两句 | 开场没直给 |
| 章节卡少于 3 张 | 长片没分章 |
| 章节卡前一句没有钩子 | 章与章之间没拉一把 |
| 前 30% 有 3 句以上不到 8 个字 | 碎句显慢 |
| 开场 20 秒内的语气写了放慢 / 一顿 | 开场拖 |

## 7. 待验证

EP.29 v2 是第一期按本标准做的。发布 48 小时后回填平均播放时长、完播率，和 EP.26（4 分钟，平均 53 秒）对比；有效的再升成硬规则。
