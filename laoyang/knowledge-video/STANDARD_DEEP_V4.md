# 老杨魔方 · 深度拆解版 v4「逻辑结构版」（2026-11-11）

> v4 不是替代 v3，是 v3 的另一种画面语法。配音、字幕、底图、留人套件、封面、发布规则全部沿用 `STANDARD_DEEP_V3.md`。
> 样片：`episodes/2026-11-11_纯管理岗正在消失_v4/`（EP.14《纯管理岗，正在消失》）。

## 1. 什么时候用 v4

判断标准：这一段的核心是**一个机制**，还是**一个事实**。

| 用 v4 结构图 | 用 v3 卡片 |
|---|---|
| 讲传导：A 导致 B，B 导致 C | 讲一个反常数字，靠证据说服 |
| 讲框架：一个问题拆成几层、几类 | 讲一段历史、一个人物故事 |
| 讲循环：飞轮、恶性循环 | 讲一份报告的几个发现 |
| 讲两种结构的对比：旧模式和新模式 | 讲政策变化，重点是变了多少 |

**按段落选，不按整期选**：一期里可以先用 v3 卡片摆证据，再切到结构图讲机制。EP.14 就是混用：开场、数据用 v3 卡片，三种位置、中层价值用结构图。

## 2. 画面原则

1. **一张主图贯穿**：先找到这期的「主图」（EP.14 是组织图：老板 → 中层 → 一线），三五个关键段落都回到它身上，每次多长出一点。结尾拉回全景，停 3 秒，可截图。
2. **跟着嘴长出来**：节点、连线、标签都挂在口播的词上（`s` = 第几个 step）。连线一笔笔画出来，流动的连线上有光点沿箭头走。
3. **讲到哪亮哪**：要强调的节点变橙（`hot`），过时的变暗（`dim`），需要时整组聚焦（`focus`），其余压暗。
4. **镜头**：`cams` 推近某一块（放大不超过 1.3 倍），讲完退回来。
5. **竖屏限制**：同屏最多 9 个节点；节点字 ≤ 8 个字，字号 38px；图向下长，不横铺；标签不压线、不压节点。
6. **颜色**：白色线框是常态，橙色只给当前重点和 AI，红色只给断点 / 冲突。

## 3. 结构图卡 `map`

```json
{"id": "k06", "type": "map", "at": "v09", "steps": ["v10|下面|s", "v11|旁边|s"],
 "data": {"eyebrow": "…", "title": "…*重点*…", "W": 920, "H": 720,
  "nodes": [{"id": "boss", "x": 460, "y": 60, "w": 240, "h": 84, "t": "老板", "n": "小字", "kind": "box", "s": 0, "hot": 2, "dim": 3, "out": 4}],
  "edges": [{"a": "boss", "b": "m0", "s": 0, "kind": "line", "via": "v", "label": "…", "lx": 14, "ly": -12}],
  "tags":  [{"x": 400, "y": 690, "t": "① 在下面", "s": 1, "kind": "tag"}],
  "bands": [{"x": 46, "y": 228, "w": 828, "h": 84, "t": "AI：…", "s": 3}],
  "cams":  [{"s": 3, "x": 460, "y": 300, "z": 1.1}],
  "focus": [{"s": 2, "ids": ["boss", "m0", "boss-m0"], "until": 3}]}}
```

| 字段 | 说明 |
|---|---|
| `nodes[].kind` | `box` 普通框 / `ai` 橙色胶囊（AI）/ `hot` 实心橙 / `ghost` 虚线占位 / `warn` 红框 |
| `nodes[].s / hot / dim / out` | 第几个 step 出现 / 变橙 / 变暗 / 消失 |
| `edges[].kind` | `line` 普通 / `flow` 橙色带流动光点 / `up` 往上报（橙）/ `break` 红色断点带 × / `dash` 虚线 |
| `edges[].via` | `v` 先竖后横（层级图）/ `h` 先横后竖 / `d` 直线 |
| `tags[].kind` | `tag` 橙字标签 / `sticker` 橙底贴纸（弹入）/ `note` 灰色小注 |
| `bands` | 横贯整排的发光带（例：AI 插在中间） |
| `cams` | 镜头看向世界坐标 (x, y)，放大 z；相邻关键帧之间 1.1 秒缓动 |

坐标是图内世界坐标：宽 920，高自定（≤ 760 时整卡能按 1 倍以上显示；带出处行的卡底边自动让开出处）。

## 4. 层级柱 `stack`

讲「层级压缩」专用：`{"max": 14, "levels": [{"n": 14, "label": "有的部门：14 层", "s": 1}, {"n": 5, "label": "以后：最多 5 层", "s": 2}]}`。横条一根根收掉，右边大数字跟着变。

## 5. 一期的骨架（含 v4 段落时）

| 位置 | 用什么 |
|---|---|
| 开场 0–5 秒 | `hook` 钩子大字卡（v3 规则） |
| 出处、数据 | v3 卡片（`text` / `duo` / `bignum` / `stack`） |
| 机制段 | `map`：主图第一次出现，跟着口播长出来 |
| 例子段 | `map`：从主图里拎出一块，画成局部图 |
| 收拢 | 回到主图，变化落在主图上（变暗、变橙、加带子） |
| 落到老板身上 | `map` 拆解树（一个岗位分两枝：交给 AI 的 / 替不掉的） |
| 金句 | `punch` |
| 结尾 | `map` 主图全景 + 评论区问题，停 3 秒 |

## 6. 质检
- 结构图内部元素由 svg 裁切，质检只查图的外框不出卡片区。
- 节点字是否压框：写稿时控制在 8 个字以内；抽帧自查。
- 其余同 v3（留人体检、越界、亮度、响度、念错字抽查）。
