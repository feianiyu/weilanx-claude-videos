# 老杨魔方 · 深度拆解版 v10「具象场景与视觉隐喻引擎」（2026-11-25）

> 来源（老杨 11-25）：在 v9（动感物理 + 自动音效 + 律动配乐 + 卡拉 OK 字幕 + WebGL2 3D 魔方专属开场）基础上，针对「正片内容展示不够形象」进行全面升级。
> 核心理念：**「听什么，就看见什么」**——把口播中的金融剧变、官宣现场、商业隐喻与多方博弈，直接变成会动的具象画面。

## 1. 一键开启（2026-11-25 起新期默认）

```json
{
  "layout": "v10",
  "morph": true,
  "tailSec": 0.8,
  "bgm": {"synth": "pulse", "src": "程序合成律动配乐 v9（无版权）"}
}
```

- `"layout": "v10"` 自动继承全部 v9 能力（`motion: "v2"`、`autoSfx: true`、`karaoke: true`、`progressBar: true`）。
- 第 1 张 `hook` 卡默认配置 `"bleed": {"brand": "cube", "dur": 2.8}`（2.8 秒 WebGL2 PBR 3D 装甲魔方片头 + 同步机械快拧音效），也可替换为 `"bleed": {"preset": "<名称>"}` 或 `"stock"`。

## 2. 新增 4 类具象视觉舞台（`core/cards_vivid.js`）

| 卡片类型 | 适用口播关键词 | 核心表现 |
| --- | --- | --- |
| **`ticker`**（金融行情终端） | 股价、市值、蒸发、暴跌、暴涨、走势 | 发光红跌/绿涨分时折线 + 脉冲成交量柱 + 拐点弹窗 + 顶部实时跳动读数 |
| **`social`**（社媒/官宣拟真卡） | 转发、官宣、刷屏、长文、发声、热搜 | 认证账号头像 + 荧光笔划重点 + 原帖/公告引用框 + 转发/热议实时跳动 |
| **`metaphor`**（6 大物理隐喻舞台） | 水管/堵点(`pipe`)、挤压(`squeeze`)、池子/水位(`reservoir`)、齿轮/飞轮(`gears`)、多米诺/连锁(`domino`)、芯片/算力(`chip`) | 2.5D 高清动态 Canvas 物理机制演示，随 `steps` 切换状态（稳态/堵塞/爆发/挤压/卡死/连锁倒塌） |
| **`actors`**（棋盘博弈群像卡） | 博弈、对峙、谁离不开谁、拉扯、牵制 | 左右阵营棋子角色 + 力量对比进度条动态倾斜 + 核心博弈点 |

## 3. 自动音效联动与永动引擎（v10.1）

- **自动音效**：`autoSfx` 已针对 v10 卡片内置专属音效映射：`ticker` 暴跌重击 + 反弹清脆提示音、`social` 官宣提示音、`metaphor` / `actors` 换场扫风 + 状态切换提示音，全部自动节流、稳定在 `-14.0 ± 0.5 LUFS`。
- **永动引擎**：v10 默认开启声画呼吸（`--lv`）、2.4 秒定时流光扫掠（`--sh`）、克制背景光尘（`mist: 0.42`）以及具象舞台全时粒子/扫描动效。
- **节奏纪律（全片 ≤ 3.5 秒）**：写新期 `lines.json` 时，全片任意两个画面变化（换卡或 step）尽量控制在 **2–3.5 秒** 内，`build.py` 会自动标出超过 3.5 秒的段落提醒加密 step 或拆卡。
