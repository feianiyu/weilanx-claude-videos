# 老杨魔方 · 深度拆解版 v9「动感与留存引擎」（2026-11-24）

> 来源（老杨 11-24）：针对「动画效果过于单一、流量/留存偏低、开场缺少专属 IP 质感」进行系统升级。
> v9 完全向后兼容 v1–v8：所有能力通过 `"layout": "v9"`（或独立开关）启用，旧期画面逐像素不变。

## 1. 一键开启方式

在期目录 `lines.json` 中写：

```json
{
  "layout": "v9",
  "morph": true,
  "tailSec": 0.8,
  "bgm": {"synth": "pulse", "src": "程序合成律动配乐 v9（无版权）"}
}
```

`"layout": "v9"` 默认自动开启以下全部能力（也可按需单独写 `false` 关闭某项）：

| 特性开关 | 默认值（v9） | 作用 |
| --- | --- | --- |
| `motion` | `"v2"` | 弹性过冲 `backOut` + 5 种语义转场（`cut` / `zoom` / `slide` / `wipe` / `rise`）+ 停留期微推进 + 步骤聚焦压暗 + 语义色 |
| `autoSfx` | `true` | 按卡片与动效锚点自动合成挂载无版权音效（`thud` / `stamp` / `chime` / `swoosh` / `riser` + 魔方片头专属 6 连音效），0.40s 自动防吵闹节流 |
| `karaoke` | `true` | 复用 `vo/*.words.json` 逐词高亮字幕（当前词橙色微弹，已读纯白，未读柔白；前 5 秒增强对比度） |
| `progressBar` | `true` | 顶部视频号安全区（`y=92px, x=104–976`）极简进度条 + 章节刻度 + 当前章节胶囊 |

## 2. 老杨魔方专属个性化开场（`bleed`）

在开场 `hook` 卡的 `data.bleed` 中支持三种来源：

1. **WebGL2 电影级 PBR 3D 装甲魔方（默认推荐，零素材、零费用）**
   ```json
   "bleed": {"brand": "cube", "dur": 2.8}
   ```
   - 2.8 秒高能三段式：0.45s 磁吸合拢重击（镜头微震 + 双层冲击波 + RGB 色散）→ 0.60/1.00/1.40s 三拍机械快拧（递增卡扣音效）→ 1.85–2.80s 旋散退场。
   - 配色变体：`cube`（熔金橙 × 翡翠绿，呼应老杨魔方 Logo）、`cube_gold`（纯黑金）、`cube_cyan`（科技青金）。
2. **自定义 `.mp4` 专属片头库（`preset` 槽位）**
   ```json
   "bleed": {"preset": "cube_gold", "dim": 0.82}
   ```
   - 优先读取本机 `~/laoyang-render/intros/<名称>.mp4`（不进 Git 仓库），其次读取 `core/assets/intros/`。
3. **每期主题免费实拍镜头（沿用 v8）**
   ```json
   "bleed": {"stock": {"q": "stock market dark", "kind": "video"}}
   ```

## 3. 语义强调色语法（`motion: "v2"`）

在保留品牌橙 `*词*` 为主色的前提下，HTML 卡片与 SVG 逻辑图同步支持：
- `*词*` → 品牌橙 `#F5A623`（核心结论）
- `!词!` → 警示红 `#FF5A4E`（亏损 / 风险 / 暴跌）
- `+词+` → 正向绿 `#3CF07A`（增长 / 利好 / 反弹）
- `~词~` → 科技青 `#4FD1C5`（AI / 技术 / 对照）

## 4. 律动配乐（`bgm.synth: "pulse"`）

在原有 `pad` 温暖和声基础上加入克制的 100 BPM 低频根音脉冲（避开人声核心中频）与三段能量包络（前 8 秒提气 → 中段退让 → 后 20% 微推），混音后仍稳定在 `-14.0 ± 0.5 LUFS`。
