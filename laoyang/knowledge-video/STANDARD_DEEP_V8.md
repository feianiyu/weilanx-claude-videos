# 老杨魔方 · 深度拆解版 v8「媒体层」（2026-11-21）

> 来源（老杨 11-21）：数字人方案调研后决定不做数字人；要求在 v7 上优化，重点是**插入视频、图片、小游戏**。
> 判断：全网深度知识视频里，用 AI 写代码做动态画面的形式已经有了名字，叫「Vibe 知识」（抖音话题十亿级播放），我们就在这个赛道里。它的问题是同质化（暗底、发光线条、粒子，人称“模型味”）。v1–v7 的画面全部是代码画的图，v8 补上代码画不出来的三样：**现场（图片 / 视频镜头）、原件（报告原页）、可以上手的模型（小游戏）**。
> v8 不替代 v7：配音、字幕、底图、封面、发布按 v3；选卡按 V5 / V6；版式和标注按 V7。新一期写 `"layout": "v8", "morph": true`。
> 演示期：`episodes/_demo_v8_媒体层/`（EP.31 文案原样，换了 5 处画面，四样都用到；已进回归测试）。代码：`core/media.js`、`core/media.py`、`core/game.py`、`core/gen_media.py`。

## 1. 什么时候用（一句话：镜头给情绪，图讲道理）

| 这一段在讲 | 用 | rel |
|---|---|---|
| 开场 3 秒、章节开头，要先把人拉进场景 | 钩子卡 / 章节卡加 `bleed`（整屏动态底图） | 不变 |
| 一个现场：港口、工厂、工地、商场、机房 | `clip` 视频镜头卡 / `photo` 图片卡 | 现场、场景 |
| 一段历史、一个场面，代码图画不出来 | `photo` / `clip`（AI 生成要标「AI 生成」） | 历史画面、场景 |
| 报告原文、政策原文、财报那一页 | `photo` 原件卡（`frame: "doc"`）+ 钉注 + 镜头推近 | 原件 |
| 一个能算的机制：涨多少、转嫁多少、利率变多少 → 结果变多少 | `play` 试玩卡（同时导出 H5 小游戏） | 算一算、互动 |

**硬规矩：**
1. 逻辑和数据仍然用图讲。视频镜头合计不超过全片 30%（build 提示）；媒体卡（photo / clip / play）不连排 3 张（不过不出片）。
2. **AI 生成的画面必须带「AI 生成」角标**（`gen` 自动加；自己写 label 也必须含「AI」）。这是平台的显式标识要求。
3. 素材库的图 / 视频必须写 `credit`（自动进出处行）；画面不是事件本身时，`label` 写「示意」。
4. 不用真人肖像照（版权、肖像权都不稳），不用影视剧截图、新闻台画面。
5. 试玩卡里的模型如果是示意（假设的工厂、假设的比例），`eyebrow` 开头写「示意」，H5 里同样显示。

## 2. 四种用法

### 2.1 `photo` 图片 / 原件卡

```json
{"id": "k10d", "type": "photo", "rel": "原件", "at": "v18", "steps": ["v18|八成以上|s", "v19|输入型通胀|s"],
 "data": {"eyebrow": "统计局原文", "title": "涨价*主要在上游*", "frame": "doc", "file": "assets/media/k10d.png", "label": "原文截图",
          "pins": [{"x": 0.5, "y": 0.49, "t": "6 个能源行业 *八成以上*", "s": 1, "side": "l"}],
          "zoom": {"x": 0.5, "y": 0.49, "z": 1.7, "s": 1},
          "cap": {"t": "邢自强：*输入型通胀*，不是需求拉动", "s": 2}, "credit": "国家统计局 10 月 CPI、PPI 解读（原文截图）"}}
```

| 字段 | 说明 |
|---|---|
| `frame` | `full` 920×700（默认）/ `wide` 920×518（16:9 横图、横视频）/ `tall` 600×800（竖图）/ `doc` 760×860（原件：纸面、整页显示，不裁） |
| `h` | 改盒子高度 |
| `kb` | 慢推，`[起, 止]` 倍数，默认图片 `[1, 1.07]`、视频 `[1, 1.03]` |
| `pan` | 焦点从 `(x0,y0)` 移到 `(x1,y1)`，0–1 的比例坐标 |
| `zoom` | 第 `s` 个 step 镜头推到 `(x, y)`，放大 `z` 倍；`back` = 第几个 step 拉回 |
| `pins` | 钉注：按**原图**的比例坐标钉，跟着慢推和推近一起走；`side: "l"` 标签放左边 |
| `cap` | 图下面一句话，可以等某个 step |
| `label` | 左上角角标：「原文截图」「示意」「资料照片」；AI 生成自动是「AI 生成」 |

v7 的版式层照样能用：`take`（图 + 结论栏）、`table`（图 + 表）、`carry` 都可以加在 photo / clip 上。

### 2.2 `clip` 视频镜头卡

字段和 photo 一样，多两个：`in`（从原视频第几秒开始）、`rate`（播放速度，0.5 = 慢放）。
- 视频在 build 时用 ffmpeg 按 30fps 抽成逐帧 jpg（只抽这张卡在屏上那么长），网页按时间取帧——**和其他画面一样是时间的纯函数**，并行渲染、回归测试都不受影响。
- 视频比卡片短：停在最后一帧（慢推还在动），build 会提示。
- 镜头 3–6 秒最好；超过 8 秒的镜头拆成两张卡，中间回到图。
- 镜头不带声音（只用画面）；配音和配乐不变。

### 2.3 `bleed` 整屏动态底图（任何卡都能加）

```json
"data": {"kicker": "...", "lines": [...], "bleed": {"gen": {"prompt": "夜晚的集装箱港口……航拍缓慢推进", "kind": "video", "dur": 5}, "dim": 0.75}}
```

- 这张卡在屏上时，媒体铺满整屏，压在卡片下面（在底图之上、压暗层之下），跟着卡片淡入淡出。
- 默认降饱和、压暗（和 v3 底图观感一致，字压得住）；`dim` 调亮度（默认 0.8）；`look: "raw"` 不调色。
- **钩子卡最该用**：开场 3 秒是流失最多的地方，一段动着的现场比静态底图更抓人。v8 期数钩子卡没有 bleed 时 build 会提示。
- 竖屏铺满要求：图片至少 1080×1920 量级；视频最好是 9:16 竖拍（AI 生成写 `ratio` 或按 frame 自动选 9:16）。

### 2.4 `play` 试玩卡 + H5 小游戏

```json
{"id": "k10g", "type": "play", "rel": "算一算", "at": "v20", "steps": ["v20|成本上升|s", "v21|卖价又提不上来|s", "v21|夹在中间|s"],
 "data": {"eyebrow": "示意 · 材料占成本六成、原来毛利 20% 的工厂", "title": "材料涨价，*利润还剩多少*",
          "inputs": [{"k": "p", "label": "材料涨价", "min": 0, "max": 10, "step": 0.1, "unit": "%", "v": 0,
                      "keys": [{"v": 5.7, "s": 1, "t": "材料涨 5.7%、一分没转嫁：利润少了 *17%*"}]},
                     {"k": "pass", "label": "能转嫁给客户", "min": 0, "max": 100, "step": 5, "unit": "%", "v": 0,
                      "keys": [{"v": 30, "s": 2, "t": "就算转嫁三成，利润还是少了 *12%*"}]}],
          "consts": {"m": 60, "o": 20},
          "outputs": [{"label": "毛利率", "f": "(100+m*p/100*pass/100-m*(1+p/100)-o)/(100+m*p/100*pass/100)*100", "unit": "%", "dec": 1, "max": 25},
                      {"label": "利润还剩", "f": "(100+m*p/100*pass/100-m*(1+p/100)-o)/(100-m-o)*100", "unit": "%", "dec": 0, "max": 100, "hot": true}],
          "cta": {"t": "评论区置顶：自己拖一拖", "s": 3}}}
```

- **片里**：屏上是一个手机小程序样子的面板（滑杆 + 结果）。每个 `key` 到了对应 step，一只手移到滑块上拖到目标值，结果数字跟着滚，拖完显示这一步的那句话（`t`）。观众看到的是「数字怎么被拖出来的」，比一张静态表更有获得感。
- **片外**：build 自动导出 `build/小游戏_<卡id>.html`：单个文件、不联网、手机上直接打开就能拖；`keys` 变成「一键看这一档」的按钮。Mac 出片机会把它放进 `待审/<期>/`。
- 公式 `f` 是普通算式，能用 `inputs` 的 `k` 和 `consts` 里的名字。**写完先在本地 H5 里拖一遍，核对片里口播说的数和公式算出来的一致**（演示期：5.7% → 利润剩 83%、转嫁三成 → 88%）。
- 一期最多 1 张试玩卡；它要有 2 个以上 key（拖两下才看得出关系）。
- lines.json 可选 `"game": {"intro": "玩之前的一句话", "foot": "页脚"}`。

**小游戏怎么给观众：** 抖音、视频号的评论区一般不能放外链，所以片里的 CTA 写「评论区置顶」时，置顶的是**玩法说明 + 去哪玩**（例如「主页 / 粉丝群 / 公众号里有链接」）。具体挂法（公众号文章、粉丝群、小红书笔记、主页链接）要老杨在各平台实测后定，定了写进本节。H5 文件可以直接发给 Claude 发布成一个可分享的网页链接。

## 3. 媒体从哪来

**默认只用免费来源（11-21 老杨定）**：原件截图 > 素材库关键词 `stock` > 素材库原链接 `url`。AI 生成 `gen` 要花钱，只在素材库确实找不到、且老杨同意时用。

| 来源 | 写法 | 谁来弄 | 注意 |
|---|---|---|---|
| **素材库关键词（默认）** | `stock: {q: "英文关键词", kind: "video"/"img", pick: 0}` | Mac 出片机 `stock_media.py` 用 Pixabay（优先，可用中文关键词）/ Pexels 免费 API 搜索、下载 | 免费；自动写「Pexels · 作者」进出处行、角标「示意」；不合适就改 `pick`（换第几条）或关键词 |
| 素材库原链接 | `url` + `credit` | Mac 出片机 `fetch_assets.py` 下载 | 用原图 / 原视频文件链接；`label: "示意"` |
| AI 生成（图 / 视频镜头） | `gen: {prompt, kind: "img"/"video", dur, ratio}` | Mac 出片机 `gen_media.py` 调火山方舟（Seedream 图、Seedance 视频） | 需要 `ARK_API_KEY`；按提示词缓存，不重复花钱；自动标「AI 生成」 |
| 老杨给的原件（报告页、截图） | `file: "assets/media/<卡id>.png"` | 老杨放进期目录的 `assets/media/`（不进仓库），或发给 Claude | `label: "原文截图"`；截图前去掉个人信息 |

`stock` 的关键词用英文写**具体画面**（`container port night aerial`，不写 `economy`）；尽量选没有人脸特写的场景。下载后出片报告会列出每条镜头的 Pexels 链接，老杨看一眼，不合适让 Claude 改 `pick`。

`gen` 的提示词写**画面**，不写字（AI 生成的字常常是错的）；脚本会自动补一句统一风格（电影感、低饱和暖色、无文字、无水印、不出现真人面孔特写）。不想要统一风格写 `"raw": true`。

缺文件时（云端构建、Mac 没有密钥、下载失败）画面是占位框，写着「视频镜头占位 / 图片占位 + 提示词」，排版照样能检查；出片报告会写「有 AI 生成画面没生成出来」，这种成片不能发。

## 4. 体检（`core/lint_visual.py`，`"layout": "v8"`）

- 不过不出片：媒体没写来源（stock / file / url / gen 都没有）；stock 没写关键词；素材库媒体没写 credit；AI 生成的 label 不带「AI」；gen 没写 prompt；试玩卡缺 inputs / outputs / keys；媒体卡连排 3 张。
- 提示：一张图片 / 镜头都没用；钩子卡没有 bleed；试玩卡没写 cta；镜头合计超过全片 30%；视频比卡片短；整屏底图分辨率不够。
- v7 的版式 / 标注提示在 v8 期数里照样跑。

## 6. 还没验证的

- Pexels 关键词自动选的镜头合不合适（要老杨在 Mac 配上免费的 `PEXELS_API_KEY` 后跑一期看）。
