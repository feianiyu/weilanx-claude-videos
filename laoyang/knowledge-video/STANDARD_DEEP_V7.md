# 老杨魔方 · 深度拆解版 v7「版式层 + 标注层」（2026-11-14）

> 来源（老杨反馈）：每期的动画看起来都一样，要不要准备一百个逻辑图自由组合，参考知名咨询公司的组合方式。
> 判断：图型已经有约 45 种（EP.24 一期就用了 14 种），观众还是觉得一样，原因是每张图的摆法都相同：一屏一张、居中、没有标注。咨询公司常用的图型也就二三十种，变化来自组合：**结论当标题、图上加标注、换版式、一页之内逐步搭建**。
> 所以 v7 不加一百张图，而是在 v6 上加两层：**版式层（8 种）** 和 **标注层（7 种）**，和现有图型自由组合。
> 新一期写 `"layout": "v7", "morph": true`。配音、字幕、底图、封面、发布规则仍按 v3；选卡仍按 V5 / V6 的内容关系识别表。
> 演示期：`episodes/_demo_v7_版式与标注/`（用 EP.24 的文案原样重排，8 种版式和 7 种标注都用到了；已进回归测试）。代码：`core/layers.js`。

## 1. 怎么写

所有新字段都写在卡片的 `data` 里，不写就和 v6 一模一样（旧期逐像素不变，回归 58/58）。

```json
{"id": "k11", "type": "balance", "rel": "取舍", "at": "v20", "steps": ["v20|6000亿元|s", "v21|收支错配|s", "v22|结构没变|s"],
 "data": {"title": "省了利息，*没改结构*", "left": {...}, "right": {...},
          "take": {"label": "兰德的判断", "t": "能买时间、降利息|解决不了*收支错配*", "s": 2},
          "ann": [{"k": "band", "on": "收支错配", "s": 3}]}}
```

`s` 和 v6 一样：第几个 step 锚点到时出现，0 = 随卡出现。

## 2. 版式层（8 种，可以叠加）

| 版式 | 写法 | 什么时候用 |
|---|---|---|
| full 整屏 | 不写 | 图本身就够说明白 |
| take 图 + 结论栏 | `take: {t, s, label}` | 图讲完要落一句判断；咨询页右边那块「所以」 |
| pair 两图对比 | `pair: {type, data, label}`，`pairDir: "v"`（上下，默认）/ `"h"`（左右） | 一边涨一边跌、前后两个时期、两本账。两半各是一张完整的卡，共用这张卡的 steps |
| table 上图下表 | `table: {head, rows, s}`，行写 `[..]` 或 `{c:[..], s, hot}` | 图讲结论，表给明细（方案构成、几年的数） |
| multi 小图并列 | 卡片类型 `"type": "multi"`，`kind: bar / ring / spark / num`，`cols`，`items: [{t, val, v, max, pts, n, s, hot}]` | 几项同类数字并排比，一眼看出谁大；rel 用「几项并列」等 |
| focus 镜头推近 | `focus: {on, z, s, back}` | 讲到某一块时把镜头推过去（上下边缘自动渐隐）；`back` = 第几个 step 拉回来 |
| note 全屏数字 + 注释 | `lay: "note"` + `notes: [{t, s, hot}]`（配 `bignum`，`parts` 可写 `[]`） | 一个大数字，旁边 2–4 条注释说它的来历 |
| carry 跨卡延续 | `carry: true` 或 `{t: "接上一张 · …"}` | 这张接着上一张讲（补口径、补限制），顶部留上一张的缩略图，观众不丢线 |

`pair` 两半会自动缩小（上下按两半总高度算，最大 0.72；左右固定 0.48），只适合内容少的卡：折线、柱状、双数、大数字。

## 3. 标注层（7 种）

`ann: [{k, on, to, t, s, c, side, unit, pad}]`。`on` / `to` 写**卡片上看得见的那几个字**（去掉空格比对），找最贴近的那个元素；找不到会在控制台报错，`qc.py` 会拦下。

| 标注 | 写法 | 用在 |
|---|---|---|
| circle 圈注 | `{k:"circle", on, t}` | 圈出关键的那个数或词，`t` 可加小标签 |
| band 高亮带 | `{k:"band", on, wide}` | 一行里的重点，`wide:true` 整行铺满 |
| tag 标签 | `{k:"tag", on, t, side:"t"}` | 给一个数贴口径、来源、性质（「全口径估算」「认定口径」） |
| callout 结论框 | `{k:"callout", on, t, side:"t/b/l/r"}` | 带引线的一句话解读，`|` 换行 |
| delta 差额箭头 | `{k:"delta", on, to, t, lift}` | 从 A 到 B 变了多少（「−7.8 万亿」） |
| bracket 括号求和 | `{k:"bracket", on, to, t, side:"r/b", unit:true}` | 几项加起来是多少（「合计 102.5 万亿」） |
| base 基准线 | `{k:"base", on 或 y, t}` | 一条参照线：去年、平均、红线 |

- `c`：颜色，`o` 橙（默认）/ `w` 白 / `r` 红。红只给冲突、断点。
- `unit: true`：标整块（找到的字所在的那一格小图、那一行），不只标那几个字。
- 标注先描线，再出文字；位置在第一帧算一次，之后只按时间变化（纯函数）。

## 4. 组合规则（咨询公司的做法换成我们的话）

1. **标题写结论，不写话题。**「隐性债：两年少了一半还多」，不写「隐性债变化」。
2. **一张图只证明一件事。** 要证明第二件事，用标注或换版式，不要再塞一组数据。
3. **每期至少 4 种版式、3 种标注。** 不要求每张卡都加；数字本身就够刺眼时，整屏最好。
4. **连着两张不用同一种版式**（整屏除外）。
5. **标注跟着口播出现**：说到「少了 7.8 万亿」那一刻，箭头才画出来。
6. **一张卡最多 2 条标注**，多了就是在画面上念稿。

`core/lint_visual.py`（`"layout": "v7"`）：版式名、标注名拼错、标注缺 `on` / `to` → 未通过；用的版式少于 4 种、标注少于 3 种、连着两张同一种版式 → 提示。
