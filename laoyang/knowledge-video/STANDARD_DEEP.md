# 老杨魔方 · 深度拆解版 标准 v1

> 2026-11-02 起草。来源：拆解样本 @宏观棱镜《财政第一本账，看懂央地财政关系和转移支付》（3:35，竖屏）。

## 1. 样本拆解

### 1.1 一句话总结
它不是在"讲知识点"，是在**带观众把一本账从头算到尾**：每个数字都能加减对上，每一段结尾抛出下一段要回答的问题，最后用前面算出来的东西，把"转移支付"重新定义成"给没被市场价格算进去的贡献补账"。

### 1.2 结构时间轴（全片 213 秒，约 1100 字，5.2 字/秒）

| 段 | 时间 | 做了什么 | 结尾留下的问题 |
|---|---|---|---|
| 0 开场 | 0–28s | 续集钩子（上期近百万播放）→ 收窄范围（四本账只讲第一本）→ 立前提（看懂它要先懂央地关系 + 转移支付） | "那这本账怎么分？" |
| 1 收入账 | 29–83s | 总量 21.6 万亿 = 税 17.6 + 非税 4 → 税收中央 8.8 / 地方 8.85 → 非税地方 3.4（85%）→ 合计中央 9.4 / 地方 12.2 → **插播新政策**（附加税口径变化，"本质没变，左口袋挪右口袋"）→ 56.5% : 43.5% | "收入地方多拿一点，那支出呢？" |
| 2 反常 | 84–120s | 支出地方 24.4 万亿占 85% → 收入 12.2、支出翻倍 → **"缺口怎么补？"** → 转移支付 10.2 万亿 → 中央资金流（收 9.4 − 自花 4.5 + 发债凑 → 转出 10.2）→ 解释常识"财政自给率 50%"从哪来 | "每个省拿的一样吗？" |
| 3 分布 + 纠错 | 121–155s | 31 省结构图 → 中西部比例高、川豫新绝对值大 → 但京沪粤也拿 → **划掉误解"富省直接给穷省打钱"** → 正确模型：先进全国池，再按事权/人口/成本/国家任务重新配置 | "为什么要搞这么大规模？" |
| 4 深层原因 | 156–204s | 统一大市场里三种流动，每种一个具体机制：劳动力（产值留沿海、养育养老在输出地）、能源（西气东输…廉价能源）、粮食（保耕地放弃高收益用地 + 仓储水利成本）→ **重新定义**：转移支付不是单向输血，是给没被市场价格充分计算的贡献补账 | — |
| 5 收尾 | 205–213s | 一句复述 + 下期从收支维度展开 + 评论区 | — |

### 1.3 内容技巧（深度从哪来）

1. **问题链驱动**：全片是 4 个环环相扣的问题（怎么分 → 缺口怎么补 → 为什么各省不同 → 为什么要这么做）。每段结尾提问，下一段回答。观众被问题拽着走，所以 3 分半看得下去。
2. **一本能闭环的账**：17.6+4=21.6；8.8+8.85≈17.6；0.6+3.4=4；9.4+12.2=21.6；12.2→24.4 是 2 倍；10.2/24.4≈一半 → 自给率 50%。数字之间能互相验证，**观众会自己算，信任就是这样来的**。前 2 分钟 18 个数字，后 1 分钟一个数字都没有，只讲机制。
3. **先数据、后机制、最后重新定义**：是什么（数字）→ 哪里反常（数字里的矛盾）→ 怎么运作（钱怎么流）→ 常见误解错在哪 → 深层为什么（三个具体证据）→ 一句话重新定义主题。
4. **立一个靶子再推倒**："富省直接给穷省打钱"——大众常识，用"京沪粤也拿"一个事实推翻，再给出正确模型。纠错比正面讲更有记忆点。
5. **结论是推出来的，不是喊出来的**：最后那句"补账"之前，劳动力、能源、粮食三个证据已经铺好。没有"我的判断"这种标签，判断从论证里自然长出来。
6. **边界清楚、系列化**："每期内容不能太多，今天先讲第一本账"——主动收窄，把剩下的挂成下一期。
7. **时效插播**：中间插一条新文件，并马上点明"本质没变"——既显得新，又不打断主线。
8. **口吻**：第一人称、口语、续集感（"我是一个很宠粉的博主"），没有口号式金句，没有煽情。

### 1.4 画面语法

- **外框常驻**（全片不变）：左上圆形 logo + @账号；第二行橙色系列标题（全片同一句，不随章节切换）；下部头像 + 橙色声波 + 账号名；两行白色粗黑体字幕带阴影；最底一根细橙线 + 英文栏目名（MACRO PRISM / 2025 FISCAL SYSTEM）+ 编号。
- **底图**：一张贴题实拍（金币堆），压暗到约 20–30% 亮度，几乎不动。
- **颜色**：黑底 + 白字 + **唯一强调色橙黄** + 灰作对照。没有第二种彩色。
- **内容区一屏一张"数据卡"**：英文小眉标（GENERAL PUBLIC BUDGET / 2025）+ 中文标题 + 一个图。全片约 14 张卡，平均 15 秒一张；卡内元素**随句子逐个加上去**（同一张卡讲 2–4 句）。
- **卡片种类**（样本里出现的）：目录卡（四本账 2×2）、焦点卡（一般公共预算 收入/支出）、问题卡（"两把钥匙"高亮）、大数字 + 构成条、分账条（中央/地方左右对半）、双数字对比、口径变化卡（A → B）、双柱对比 + 倾斜贴纸"缺口怎么补？"、资金流水线（9.4 → 4.5 → 10.2 带箭头）、31 省堆叠柱（先全景再推近 + 高亮框）、划掉的误解 + 机制图、节点流动图（中西部 ●●●● 沿海）、三栏收束 + 结论框 + 下期预告。
- **动效极少**：卡片淡入 + 轻微上移约 0.4 秒，旧卡淡出约 0.2 秒；强调只用四种——高亮框、删除线、倾斜贴纸、图表推近。**没有粒子、雾化、光扫、烟雾**。
- 声音：响度 −20.8 LUFS、动态范围 2.5 LU，人声为主，背景乐极轻。

## 2. 为什么《万历十五年》显得浅（对照）

| | 样本 | 我们的万历 |
|---|---|---|
| 篇幅 | 213 秒 / 约 1100 字 | 约 70 秒 / 18 句（标准写死 60–75 秒） |
| 主线 | 4 个环环相扣的问题 | 没有问题，是"六个人 → 病根 → 今天 → 判断"的模板 |
| 中段 | 一本能闭环的账，层层推 | 六个人各一句形容词（最敢改/最会圆/最清廉…），是**罗列**，不是分析 |
| 核心概念 | 转移支付的运作机制讲透 | 书里最关键的"数目字管理"一个字没提；"道德代替制度"只是断言，没讲为什么必然如此 |
| 纠错 | 推倒一个大众误解 | 没有 |
| 结论 | 从三个证据推出来的重新定义 | "个人努力决定下限，系统决定上限"——口号，前面没铺证据 |
| 联系现实 | 无需硬联系，机制本身就有用 | "很多团队也是这样"一句话跳过去，没有桥 |
| 画面 | 一色、一卡、一图，帮观众算账 | 粒子/雾化/光扫/烟雾 + 切换头条 + 进度条，画面和内容抢注意力 |

**根因**：知识分享版的叙事骨架（钩子数字 → 背景 → 变化 → 亲历 → 我的判断 → 二选一提问）本身就是套路模板；60–75 秒的时长又逼着每个点只能说一句。问题不在某一期写得差，在模板。

## 3. 新流程：确定主题后，怎么写出一篇有深度的稿子（核心）

每一步都有产物，写进期目录的 `PLAN.md`，第 5 步完成后发老杨确认。

**第 1 步 · 把话题改写成一个问题**
话题不是问题。"转移支付"是话题，"地方收入只有一半，另一半钱从哪来？"才是问题。
- 产物：一句问题。要求：观众心里有、但答不全；答案不是一个形容词。
- 自检：问题能不能用"是/不是"回答？能 → 太浅，重写。

**第 2 步 · 划边界、立前提**
- 这期只讲什么，明确说出来（"今天先讲第一本账"），其余挂系列。
- 找"前提"：要回答这个问题，观众必须先懂的那个结构（样本里是"央地关系 + 转移支付"）。前提就是本期主线。
- 产物：本期讲 / 不讲 / 下期讲 三行。

**第 3 步 · 搭问题链（4–6 个）**
每一环回答上一环、抛出下一环。默认六段式：

| 环 | 回答什么 | 典型句式 |
|---|---|---|
| ① 是什么 | 总量和结构 | "这本账一共 X，由 A 和 B 组成" |
| ② 哪里反常 | 数字或事实里的矛盾 | "收入才 X，支出却是 2 倍，缺口怎么补？" |
| ③ 怎么运作 | 钱 / 权 / 人 / 信息怎么流 | "中央收 X，自己花 Y，再转出 Z" |
| ④ 常见误解错在哪 | 推倒一个大众说法 | "这说明它不是……而是……" |
| ⑤ 为什么非这样不可 | 深层原因，**3 个具体证据** | "劳动力是这样，能源也是如此，粮食方面……" |
| ⑥ 重新定义 | 一句话重说主题 | "所以 X 从来不是 A，而是 B" |

- 产物：6 个问题 + 每个问题的一句话答案。
- 自检：**把每段结尾的提问删掉，段落之间还连得上吗？** 连得上 → 是罗列，不是链。

**第 4 步 · 建证据账本**
- 数据：选一套能闭环的数（加减、比例能互相验证），写进 `FACTS.md`，每条一手出处（政府公报、统计年鉴、原书页码）。未核实的不用。
- 每个数字只出现一次、只服务一个对比；数字放前半段建立信任，后半段讲机制用具体事例。
- 非数据题（读书、历史、管理）：证据 = 原书关键概念的原话 + 具体事件 + 因果链。读书题必须讲清**作者最核心的那个概念**（万历就是"数目字管理"）。
- 产物：FACTS.md（数字 / 引文 / 事件，各带出处）。

**第 5 步 · 写结论句，并倒查**
- 写出第 ⑥ 环那句重新定义。
- 倒查：这句话的每个词，前面有没有证据撑着？有一个词撑不住 → 补证据或改结论。
- 禁用：没有证据的金句、"我的判断"标签、"你是哪一种"二选一提问。
- 产物：结论句 + 它依赖的 3 条证据编号。→ **把 PLAN.md 发老杨确认**。

**第 6 步 · 写成口播稿**
- 2:30–4:00，800–1300 字；本人音色 +15% 约 5 字/秒。
- 第一人称、口语；开头 30 秒内必须出现"本期问题"和"前提"。
- 中间可插一条时效信息（新政策 / 新数据），插完立刻点明"本质是什么"。
- 结尾 = 一句复述 + 下期讲什么 + 评论区。
- 每句标出它挂哪张卡、卡上加什么元素（第 5 节）。
- 产物：lines.json 文案（v01…vNN）→ 发老杨确认后一字不改。

**第 7 步 · 稿子自检清单**（全过才进制作）
- [ ] 本期问题一句话能说清，不能用是/否回答
- [ ] 有 4–6 环问题链，删掉提问句后段落连不上
- [ ] 至少一个反常点、一个被推倒的常见误解
- [ ] 深层原因有 3 个具体证据，不是形容词
- [ ] 结论句每个词都有前文证据
- [ ] 数字能闭环，每个都有一手出处
- [ ] 读书题讲清了作者的核心概念
- [ ] 没有口号金句、没有"我的判断"、没有二选一提问
- [ ] 观众看完能复述出一个模型（一张流程/结构）

## 4. 选题适配

最适合：有一本"账"或一个"结构"可以算的题——财政、税、社保、医保、产业链、公司财报、政策条款、读书里的制度分析。
不适合：纯观点、纯情绪、无法验证的预测。
现有选题池（政策法规为主、读书为辅）可以直接用，每个题先过第 1 步：改写不成问题的先放一边。

## 5. 画面规范（老杨魔方版）

### 5.1 外框（core/shell，全片常驻，每期只换文字）

| 区域 | 位置（1080×1920） | 规格 |
|---|---|---|
| 左上品牌 | x60, y150 | 立方体 logo 64px 亮绿 #2BE08A +「老杨魔方」36px 900 白 +「企业经营观察」24px 灰，字距拉开 |
| 系列标题 | 居中, y250 | 44px 900 橙 #F5A623，**全片不变**（如"重读《万历十五年》：一个帝国为什么算不清账"） |
| 内容区 | x80–1000, y420–1320 | 只放卡片 |
| 来源注 | 内容区左下 | 24px 灰，"数据来源：… / 示意" |
| 声音条 | 居中, y1395 | 圆形底立方体 logo 104px + 橙色声波（跟人声）+「老杨魔方」 |
| 字幕 | x60–1020, y1545 | 48px 900 白，两行内，黑色阴影 |
| 页脚 | y1745 | 细橙线 + 「LAOYANG CUBE / 栏目名」+ 期号 |
| 平台遮挡 | y>1800、右侧点赞栏 | 不放内容 |

- **底图必须是高质量实拍**（2026-11-02 老杨要求）：
  1. 来源：Pexels / Unsplash 等可商用图库，贴题、低调光（暗部多、主体清楚）；在 FACTS 或 lines.json 的 `note` 里记作者、编号和许可。
  2. 分辨率：下载**原图**（Pexels 链接不要带 `?w=`/`?h=` 缩略参数）；竖屏裁切后实际用到的高度 ≥ 1962px，build 会检查，不够就报「底图分辨率不够」，换图，不许放大。
  3. 不重新压缩：build 原样复制原图；渲染逐帧 PNG 无损截图 + crf 15；外壳加固定颗粒层压住暗部色带。
  4. 发布版体积：job.json 设 `publish_mb: 120`（约 3.5 分钟 ≈ 4.5 Mbps），不要用默认 25MB，否则底图会糊。
  5. 一期默认一张，最多三张（`bgs` 列表，`from` = 从哪张卡开始，1 秒交叉切换）；`pos` 调裁切位置，`dim` 调亮度。
  6. 压暗由外壳遮罩统一做（上暗下亮：卡片区约 10–20% 亮度，下半部约 25–30%），不要在原图上烘焙；细节特别多的图再用 `dim`（0.6–0.9）压。
  7. 选图避开字幕区（y1380–1730）有密纹的构图（树叶、栏杆、文字招牌），否则字幕和来源注会被吃掉——万历深度版首次出片的教训。
- 颜色：黑 + 白 + 橙 #F5A623 + 灰 #8E8A82；绿只用于 logo。同一屏只有橙一种彩色。
- 字体：Noto Sans SC Black / Bold（黑体，不用宋体）。
- **取消**：切换头条、进度条、粒子、雾化、水流、光扫、碎裂、烟雾、片尾粒子 logo。

### 5.2 卡片库（cards.js，跨期复用，每期在 lines.json 里配置）

| 卡 | 用途 | 关键元素 |
|---|---|---|
| `index` 目录卡 | 交代全局、本期在哪 | 2×2 / 1×3 格，当前项橙框 |

| `question` 问题卡 | 抛出本期问题 / 前提 | 一句问题，关键词橙色高亮 |
| `bignum` 大数字卡 | 总量 | 橙色大数字 + 构成横条 |
| `split` 分账条 | 两方怎么分 | 左右分割条 + 两端数值 + 一句判语（"基本对半""地方拿大头"） |
| `duo` 双数对比 | 两个数并列 | 两列数字 + 百分比 |
| `shift` 口径变化 | 政策前后 | A → B + 一行说明 |
| `bars` 柱状对比 | 反常 | 2–3 根柱 + 倾斜贴纸提问 |
| `flow` 资金/流程线 | 怎么运作 | 节点 → 节点 → 节点，数值逐个出现 |
| `chart` 多项图 | 分布 | 堆叠柱 / 横条，先全景后推近 + 高亮框 |
| `myth` 误解卡 | 推倒常识 | 划掉的旧说法 + 正确机制图 |
| `chain` 因果链 | 为什么 | 3–4 个框竖排，最后一个橙框 |
| `close` 收束卡 | 重新定义 | 三栏证据 + 结论框 + 下期预告 |

规则：
1. 一张卡讲 2–4 句；卡内元素挂在句子里的词上逐个出现（锚点 `T('v05|缺口|s')` 机制保留）。
2. 平均 10–20 秒换一张卡；全片 10–16 张。
3. 每个实数旁注来源；示意图注"示意"。

## 封面规则 v2（2026-11-04 老杨）

问题：旧封面的绿色大标题写成悬念或情绪句（「同一个皇帝 为什么盛世变危机」「桥修好了 钱却更紧了」），看不出这期讨论的是唐朝盛世转衰、还是土地出让收入；「甲供工程不能按3%了」也没点出是增值税法；长标题还在竖屏上被截断。

规则：
1. **绿色大标题 = 这期讨论的主题，直说**。两行：第一行点题（讨论的对象 / 话题），第二行点结论或核心变化。看到标题就知道是「唐朝盛世转衰」还是「增值税法的变化」。
2. 必须在 `lines.json → cover` 里写 `topic`（主题词，如「增值税法」「盛世转衰」「土地出让收入」），**标题里必须含它**；深度版缺 `topic` 或标题不含它，`core/cover.py` 直接报错不出图。
3. 悬念、反问、情绪词、具体数字钩子放到**白色副标**（最多两行，用 `<br>` 分行）。副标不重复标题。
4. 标题最多两行；字号自动从 150px 缩到放得下（最小 96px），副标自动缩到 44px；放不下就报错，改短文字，不许截断。
5. 事实口径：标题和副标里的数字、判断，必须在 FACTS.md 里有一手出处；报告摘要类的二手数字副标要写清「报告摘要」或留在口播里不上封面。

|---|---|---|---|

## 7. 代码（已落地，2026-11-02）

与知识分享版共用 `core/` 的配音、字幕、混音、渲染、出片机；lines.json 写 `"style": "deep"` 即走深度版：

| 文件 | 作用 |
|---|---|
| `core/shell_deep.html` | 第 5.1 节外框（品牌、系列标题、来源注、声音条、字幕、页脚、底图层、颗粒） |
| `core/cards.js` | 第 5.2 节卡片库 + 第 5.3 节动效；纯函数 `renderCards(t)` |
| `core/build.py` | `style: deep` 分支：读 `frame` / `cards` / `bgs`，卡片时间挂锚点，底图分辨率检查，`bgm: {"synth":"pad"}` 合成垫底音乐 |
| `core/render.py` | 深度版逐帧 PNG + crf 15 |
| `core/fetch_assets.py` | 下载 `bgs` 里的原图 |

lines.json 深度版字段：

```json
"style": "deep",
"frame": {"seriesLine": "全片不变的橙色系列标题", "column": "LAOYANG CUBE / 栏目", "ep": "EP.08"},
"bgs": [{"file": "assets/bg.jpg", "url": "原图地址", "note": "作者 / 编号 / 许可", "from": "k05", "pos": "50% 50%", "dim": 1}],
"bgm": {"synth": "pad"}, "bgmUnder": 19,
"cards": [{"id": "k01", "type": "bignum", "at": "v03", "steps": ["v04|8.8|s", "v05|地方|s"], "data": {...}}]
```

- `at`：句子 id（句首前 0.3s 换卡）或锚点；`steps`：卡内第 n 个单元出现的锚点。各卡 `data` 字段见 `core/cards.js` 顶部注释，`*词*` 橙色强调，`|` 换行，`src` = 来源注。
- 每期目录：`lines.json` + `PLAN.md`（7 步）+ `FACTS.md`（逐条出处）；可选 `scenes.js` / `scenes.css` 加本期专用卡。
- 范例：`episodes/2026-11-03_万历十五年_深度版/`（`gen_lines.py` 生成 lines.json）。
- 新一期：复制范例目录，改 PLAN → FACTS → 文案 → cards；`fake_vo → build → render snap` 自查后推 `render/<期>`，job.json 带 `"publish_mb": 120`。

## 8. 范例：用新流程重做《万历十五年》

**第 1 步 问题**：一个管着上亿人口的帝国，为什么连自己的账都算不清？——黄仁宇说这才是明朝的病根。
**第 2 步 边界**：本期只讲"数目字管理"这一个概念和它怎么拖垮六个人；不讲人物八卦；下期讲一条鞭法为什么没救下明朝。前提 = 先懂"数目字管理"是什么。

**第 3 步 问题链**

| 环 | 问题 | 答案要点 | 卡 |
|---|---|---|---|
| ① | 1587 年为什么"无事可记"，却被写成一本书？ | 作者要看的不是事件，是一个系统怎么运转 | question |
| ② | 管这么大的国家，靠什么管？ | 两种办法：数目字管理（可核算、可追责）vs 道德管理（看表态、看礼法）；明朝走后一条 | focus |
| ③ | 为什么算不清？ | 税额定额化、地方层层自报、开支无统一核算等具体机制 [待核：原书财政章节具体例子与数字] | flow |
| ④ | 常见误解：是坏人害了好人？ | 划掉。张居正靠个人权威推改革，算得清账却得罪所有人，死后被清算；问题在系统奖励什么 | myth + chain |
| ⑤ | 为什么六个人都输？ | 三个证据：海瑞（道德完美，按祖制办事办不通）、戚继光（靠山一倒即罢官）、皇帝（被礼法绑住，只能消极对抗）[待核：各人章节原文] | chain |
| ⑥ | 重新定义 | 不是人不行，是一个算不清账的系统，只能用道德管人；而道德管理必然奖励表态、惩罚做事 | close |

**第 5 步 结论句依据**：黄仁宇原话"中国二千年来，以道德代替法制，至明代而极，这就是一切问题的症结"[待核：版本与页码] + ③④⑤ 三环证据。

完整稿见 `episodes/2026-11-03_万历十五年_深度版/`（PLAN.md / FACTS.md / lines.json）。
