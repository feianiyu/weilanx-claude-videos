## v1.2 · 2026-10-21 · 进仓库 + 自动回归 + 迭代制度
- 六种核心观点文字效果（粒子 / 雾化 / 水流 / 光扫 / 碎裂 / 逐字）由「实验」升为**标准**（用户看过演示后认可），STANDARD §5.2 写入 8 条使用规范和音效配对。
- 新增 `core/regress.py`：占位底图 + 全静音构建 4 个范例期，37 帧与基准图逐像素对比 + 越界 + 控制台报错；GitHub Actions 对每个改到本目录的 PR 自动运行。实测：同机重跑差为 0；改一个颜色常量会有 6 帧报错。
- 新增 ITERATION.md（迭代制度）、EFFECTS.md（效果登记表，含「换场景怎么演」）、BACKLOG.md、templates/复盘.md。
- `fetch_audio.py` → `fetch_assets.py`，同时下载底图；底图、BGM、音效都不进公开仓库。
- build：缺底图时用占位色；`LY_REGRESS=1` 回归模式。
- render：`part` 的输出路径改为绝对路径（之前相对路径会写错目录）。
- 文字「粒子 / 吹散」的随机轨迹改为按粒子位置取种子（原来按序号）：跨机器字体抗锯齿差一两个边缘点时不再打乱全部粒子。GitHub 上首跑发现：37 帧里 35 帧与本机一致（均差≈0.3），只有这两帧不一致；改后基准图重生成（文字演示期的粒子轨迹有变化，属有意改动）。
- 回归测试在 GitHub 上把逐帧结果写成检查注释和步骤摘要。
- 基准图首次生成。
