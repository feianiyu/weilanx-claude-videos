> 2026-11-06 起草（老杨提出：按知识爆款视频的方式升级深度管线；开场话术必须优化；语速再快 5%；动画表现再丰富）。

## 1. 一张表：v2 比 v1 改了什么

| | v1 | v2 |
|---|---|---|
| 开场 | 没有硬规定，容易写成「今天我们这期深度分析……」 | **前 5 秒必须抛冲突**；开章名义的话术（「今天/本期/这期我们……分析/解读」「大家好」「接下来我们来……」「报告指出……」）**build 直接报错不出片** |
| 结尾 | 一句复述 + 下期预告 + 评论区 | 加**决策桥接**：回扣开头的冲突，落到一张「回去重新想的几件事」决策清单卡；`lines.json` 必填 `decision` |
| 语速 | 复刻音色 ×1.15 | **×1.21**（= 1.15 × 1.05），v2 默认值，`voice.tempo` 可覆盖 |
| 卡片 | 13 种「拆解」型 | 再加 6 种（条文划线、折线、瀑布、天平、四象限、决策清单），共 19 种；新增 4 种动效 |
| 节奏 | 平均 10–20 秒换一张卡 | 平均 **8–15 秒**；每 3 张卡至少 1 张「非拆解型」；中段有一次回钩 |
| 封面 | 绿色大标题 | **封面模板 v3**（见 §5），按老杨给的样板重做 |

启用：`lines.json` 顶层写 `"v": 2`（与 `"style": "deep"` 并列）。

## 2. 开场（最重要的一条）

### 2.1 目标
观众在第 5 秒决定划走还是看下去。第 1 句不是「介绍这期内容」，而是**让观众觉得「这事和我有关，而且我没想明白」**。

### 2.2 结构（共约 30 秒）

| 时间 | 做什么 | 例 |
|---|---|---|
| 0–5 秒 | **钩子**：1 句，≤30 字，直接给冲突 | 「你花两个亿买下一家公司，最值钱的东西却没跟过来。」 |
| 5–15 秒 | **立问题 + 点代价**：这个冲突为什么会发生、不弄清楚你会吃什么亏 | 「买来的是三百个人，客户和数据都留在了原来的系统里。」 |
| 15–30 秒 | **收窄 + 许诺**：这期只讲哪一块；看完你能重新判断什么 | 「这期只讲一件事：AI 时代，收购到底该买什么。」 |

### 2.3 五种钩子（选一种，不要混）

| 钩子 | 句式 | 示例（数字、事实须在 FACTS.md 有一手出处，下例为写法示范） |
|---|---|---|
| ① 冲突 | 做了 A，结果却是 B | 「桥修好了，钱为什么反而更紧了？」 |
| ② 反常数字 | 一个说不通的数 | 「同样一百万，地产能养4.6个人，高科技只能养3个。」 |
| ③ 具体决策 | 直接问到观众手上的那件事 | 「甲供工程，你签新合同还在按3%算吗？」 |
| ④ 推倒常识 | 先说一个大家都信的，再打脸 | 「都说盛世靠明君，可开元盛世是怎么烂掉的？」 |
| ⑤ 代价倒计时 | 不做 X，会在 Y 时间点吃亏 | 「明年1月1日起，这笔进项你抵不了了。」 |

### 2.4 禁用清单（`core/lint_opening.py` 自动检查开场前两句）

| 禁用 | 例 | 改成 |
|---|---|---|
| 开章名义 | 「今天我们这期深度分析高盛的研究报告」「本期我们来聊聊增值税法」 | 直接说冲突，报告 / 法律名放到第 2、3 句作为出处 |
| 问候 | 「大家好」「欢迎来到老杨魔方」 | 删。品牌靠外框，不靠嘴说 |
| 过门 | 「接下来我们一起看看」「首先我们来」 | 删，直接进内容 |
| 结论前置式 | 「报告指出，高科技撑不起就业」 | 先放冲突或数字，把「报告指出」挪到后面当出处 |
| 太长 | 第 1 句超过 30 字 | 拆成两句，第 1 句只留冲突 |

> 对照（2026-11-06 老杨举的例子）：
> ✕「今天我们这期深度分析高盛的研究报告，」
> ✓「同样一百万，地产能养4.6个人，高科技只能养3个。高盛一份报告，把这笔账算出来了。」
> 报告是谁出的，放在第 2 句，而且是**证据**，不是**开场白**。

### 2.5 全片的「爆款」写法（沿用 v1 的深度，再加这些）

1. **一句一个信息，≤22 字**。长句拆开，口播语速更快，长句观众跟不上。
2. **多用「你」**：「你的合同」「你的账」，少用「企业」「相关方」。
3. **中段回钩**：全片约 40% 处再抛一个小悬念（「但还有一个数，更说不通」），防止第二段掉人。
4. **数字出现的第一秒就有画面**（数字滚动 / 柱子长出来），不让观众只听。
5. **结尾回扣开头**：开头那个冲突，结尾用推出来的结论一句话解开；然后落到决策清单；最后一句是评论区的**一个具体问题**（不是二选一，不是「你怎么看」）。
6. 不要口号金句、不要「我的判断」标签（v1 已有，继续有效）。

### 2.6 感觉词（2026-11-08 加，视频号 81 条实测）

> 老杨原则：**不做真人出镜，不靠真人出镜改数据；靠文案。** 文案有没有感觉词，决定观众能不能被情绪打动、愿不愿意转给另一个老板。
> 诊断全文：项目文档 `管线/视频号数据诊断_2026-11-08.md`。

**数据**（同一个账号、同一批受众，只看标题和描述用词）：

| 文案 | 条数 | 播放中位 | 3 秒划走 | 完播 | 转发率 |
|---|---|---|---|---|---|
| 有感觉词、没有知识框架词 | 19 | **2016** | **33%** | **9.1%** | **1.06%** |
| 只有知识框架词 | 21 | **614** | **47%** | **4.9%** | **0.71%** |

流失全部在开场（片长 20% 处只剩 9%，之后曲线很平），所以开口两句决定一切。视频号先在社交关系链里分发：好友点赞、转发把作品推到下一级流量池；3 秒内划走会被判为没吸引力。老板转发，是因为「这说的就是我」，不是因为信息量大。

**2.6.1 开口两句 = 感觉词 + 具体处境 + 「你/老板/我们」**（三样缺一样就重写）
- 感觉词（从自己爆款里来，`lint_opening.py → FEEL` 可加）：危险、断裂、透支、白干、保不住、说不清、对不上、拖下去、卡住、多交、来不及、说变就变、难做、慌、苦、明明……却……
- 具体处境：签合同、发工资、交税、回款、贷款到期、招标、验收……
- 光堆感觉词没用（《企业家创造明天》用了至暗、苦、困、绝望，811 播放）：必须落到一个具体处境上。

**2.6.2 五个句式**（都是自己账号验证过的）

| 句式 | 原句 | 播放 |
|---|---|---|
| 否定排比 | 什么样的经济不好最危险？不是增长放缓，也不是产业调整，更不是短期阵痛，而是底层逻辑已经断裂。 | 31.4 万 |
| 倒计时 | 金税四期刚刚拉开合规的序幕，到 2028 年将实现闭环。 | 7.6 万 |
| 损失感 | 我们过去的繁荣，其实是在提前透支未来。 | 2.0 万 |
| 明明…却 | 明明每天都在创造就业、交税、承担风险，却始终活在一种不确定感里。 | 6038 |
| 反差对照 | 公司是有限责任，但老板的人生却经常承担无限责任。 | 2669 |

**2.6.3 第 1 句不许出现知识框架词**（build 报错）：解读、研报、新规、范式、赛道、从哪里来、长坡厚雪、一文看懂、科普。「如何 / 模式 / 机制 / X 个 / X 条」提示。这些词可以放在第 3 句以后当出处或结构，不能当开口。

| ✕ 原开口（播放 / 3 秒划走） | ✓ 改成 |
|---|---|
| 增值税法新规：工程企业老板新签合同必看（358 / 51%） | 同一份合同，今年签和去年签，你要交的税可能不一样，而且是你自己签进去的。 |
| 一般公共预算收入从哪里来（574 / 43%） | 你交的每一笔税，最后都记在一本账上。这本账，现在还平得了的城市有几个？ |
| 经济下行最容易做错的四个决定（588 / 61%） | 很多公司不是死在寒冬里，是死在老板寒冬里做的那个决定上。 |
| 财税合规先看哪三条？（1827 / 60%） | 很多老板不是被查出来的，是被自己三年前的一个习惯拖下去的。 |

**2.6.4 结尾一句：替老板说出他说不出口的话**（决定转发）。在决策清单卡之前或之后放一句能截图的话，回扣开头的冲突。例：「顺的时候别狂，低的时候别慌。」「动力换了，布局没换，等于什么都没换。」

**2.6.5 发布文案写进 `lines.json → publish`**（build 生成 `发布文案.md` + `publish_meta.json`；出片机交付时在成片目录里拼好 `发布_视频号/`（video.mp4 + cover.png + meta.json），直接就是发布台 `hub.py submit shipinhao` 要的格式）：

```json
"publish": {
  "title": "6–16 字（空格问号都算字），老板的处境或代价，含感觉词或是问句；不写知识点；不许逗号顿号句号，用空格代替（发布台规则，只允许《》“”：+？%）",
  "desc": "第一行 = 开口第 1 句（信息流只露这一行），第二行起可补一句；话题由 tags 自动接在末尾",
  "dy_title": "可选：抖音·老杨魔方标题 ≤30 字，不写则发布台自动改写",
  "tags": ["#民营企业", "#老板思维", "#税务合规"],
  "pin": "置顶评论：一个具体问题（可选）"
}
```

- 标签固定 3–4 个：**1 主**（`#民营企业`，必带）**+ 1 支柱**（①政策合规账 `#老板思维` / ②组织管理账 `#企业管理` / ③并购资本账 `#企业并购`）**+ 1–2 题**（大众会搜的词：`#金税四期` `#现金流` `#应收账款`）。
- 不用冷门专业词（#一般公共预算、#分包款支付）和跑题词（#朱婷、#Deepseek故障、#vibe知识大赏）。
- 封面主标题仍按 §5.4 点明「讨论什么」，感觉词放封面摘要和短标题。

**2.6.6 及格线**（发布 48 小时回填）：3 秒划走 ≤35%、片长 20% 处留存 ≥15%、转发率 ≥1%。

### 2.7 留人套件：在最容易划走的时间段加画面和情绪（2026-11-08 加，`lines.json` 写 `"retain": true` 启用）

> 视频号后台：流失全部集中在**开场到片长 20%**（3 秒内划走 47%，20% 处只剩 9%），之后曲线很平。所以留人手段只砸在这一段和结尾转发点，**不是全片加特效**——v1 定下的「动画不重要，内容和观点最重要、不要花哨」仍然有效：不加粒子、雾化、光扫。

| 时间段 | 观众在想什么 | 管线怎么做 | 代码 |
|---|---|---|---|
| **0–1 秒** | 这是什么？跟我有关吗？ | 第 1 张卡必须是**钩子大字卡** `hook`：开口那句冲突直接用大字砸在屏上（0 秒就在，不等配音），橙色只给感觉词。底图开场**亮一档、快推近**（3 秒内收回到正常压暗），首帧就是一张有冲击的图，不是一块黑底 | `hook` 卡、`slam` 动效；外壳 `retain.lift` |
| **1–5 秒** | 值不值得听下去？ | 钩子分 2–3 行**依次砸出**（每行隔 0.35 秒），第 3 行挂在第 2 句的锚点上——画面跟着话往前推，不停 | `hook.lines` 写 `{t, s}` |
| **全片字幕** | （情绪） | 字幕里的**感觉词自动变橙**（查实、罚、慌、要命、说不清、白干……，词表 = `lint_opening.FEEL_SUB`），观众不用听也能抓到情绪 | `retain.feel`（默认开） |
| **5 秒–片长 20%** | 还在铺垫？划走 | 画面**每 ≤5 秒必须变一次**（换卡 / 卡内加一步 / 换底图）。build 自动算，超了不让出片 | `retain.maxGap`（默认 5） |
| **约 40%** | 第二段开始走神 | 沿用 §2.5 中段回钩：一张 `sticker` 贴纸或 `stamp` 印章 + 一句「但还有一个数，更说不通」 | 已有 |
| **结尾** | 要不要转给别的老板 | **金句卡** `punch`：全屏一句能截图的话（回扣开头的冲突），然后才是决策清单 | `punch` 卡 |

**写法**

```json
"retain": true,                    // 或 {"lift": 3.0, "feel": true, "maxGap": 5.0}
"cards": [
 {"id": "k00", "type": "hook", "at": "v01", "steps": ["v01|一家加油站|s"],
  "data": {"kicker": "金税四期 · 真实案例",
           "lines": ["换台收银设备", "销售数据就能*凭空消失*？", {"t": "一家加油站，*真这么干了*", "s": 1}]}},
 …,
 {"id": "k09p", "type": "punch", "at": "v18", "steps": ["v18|是业务|s"],
  "data": {"text": "查的从来不是账面好不好看|是业务*说不说得清*", "sub": "金税四期自查五问"}},
 {"id": "k10", "type": "check", …}
]
```

- 钩子每行 ≤10 字（字号随最长一行自动缩，最大 96px）；`kicker` 是左上橙底小标（话题 · 案例 / 数字 / 倒计时）。
- 金句卡 `|` 换行，每行 ≤12 字；`*词*` 橙色只放感觉词。
- **开场底图要选「有事发生」的图**（收银台、工地停工、账本、空办公室），不是抽象纹理；`bgs` 第一张就是它，后面可以在第 2–3 张卡换回常规底图（`from`）。
- 演示期：`episodes/_demo_retain_留人套件/`（内容取自待发的《金税四期自查五问》改写稿）。
- 验收：发布 48 小时看后台「3 秒划走」和「片长 20% 处留存」，及格线见 §2.6.6；和没加套件的期数对比，进 `管线/视频号数据诊断` 复盘。

## 3. 结尾：决策桥接（选题测试落到稿子上）

选题测试：「这期看完，企业家会因此重新想一想他的哪个具体决策？」——v2 要求这句话**写进成片**：

- `lines.json → decision`：一句话写清那个决策（缺了 build 报错）。例：「收购时，要不要为人头付溢价，还是为数据、入口和客户付钱」。
- 倒数第二到第三句用 `check` 卡（决策清单）：2–4 条「回去重新想的事」，每条 ≤14 字，副行一句判断标准。清单**只列问题，不替老板做决定**。
- 纯历史、纯宏观的内容，没有这张卡就写不出来 → 说明没过选题测试，别硬做。

## 4. 语速

- v2 默认 `voice.tempo = 1.21`（复刻音色 ×1.15 再 ×1.05）。`core/align_chars.py`、`core/gen_vo_volc.py` 已按 v2 取默认值；lines.json 里显式写了 `voice.tempo` 则以它为准。
- 文案字数：同样 3 分钟，字数可以比 v1 多约 5%（≈ 5.3 字/秒）。建议全片 2:30–3:30，800–1200 字。
- 配音出来后听一遍：数字、法条名、多音字（Mac 出片机已自动抽查）；太快的数字句，在 `tts` 字段里用逗号加一点停顿，不要改回去降速。

## 5. 画面

### 5.1 新增 6 种卡片（`core/cards.js`，演示：`episodes/_demo_deep_v2_新卡片库/`）

| 卡 | 用途 | 关键字段 | 动效 |
|---|---|---|---|
| `quote` 条文卡 | 法条 / 合同 / 报告原文，**关键词随口播逐个划线**，可盖章 | `from` 出处一行、`parts:[ "普通", {t,s} ]`、`stamp:{text,s}` | 划线（mark）、盖章（stamp） |
| `line` 折线卡 | 一个量怎么一路走下去 | `pts:[{x,y}]`、`from.label`、`end:{s,label}` | 折线从左到右擦出（wipe） |
| `waterfall` 瀑布卡 | 一笔账怎么从 A 变成 B（利润桥、估值桥） | `steps:[{name,v,total}]`（v 负为减） | 柱子逐根长出 |
| `balance` 天平 | 两边掂量，权重换边 | `left/right:{k,v}`、`tilt:"left\|right"`、`verdict` | 横梁倾斜、托盘升降（tilt） |
| `matrix` 四象限 | 把几个对象摆进坐标，一眼分高下 | `xl/yl`、`quads`、`dots:[{label,x,y,on}]` | 圆点逐个落下 |
| `check` 决策清单 | 桥接段专用：回去重新想的事 | `items:[{t,n}]`、`stamp` | 方框描勾（tick）、盖章 |

写法与 v1 卡片一样：`at` 挂句子、`steps` 挂句内锚点（`'v05|词|s'`）；数值全部写进 `data`，示意数字必须标「示意」。

### 5.2 新增动效（仍是帧号的纯函数，不用随机、不用真实时间）

| 动效 | 时长 | 用在 |
|---|---|---|
| wipe 擦出 | 1.2s | 折线 |
| mark 划线 | 0.45s | 条文关键词 |
| tilt 倾斜 | 0.9s | 天平 |
| stamp 盖章（放大回落） | 0.2s | 「没写进去？」「多问一句」类一句话，全片 ≤2 次 |
| tick 描勾 | 0.3s | 决策清单 |

v1 里取消的（粒子、雾化、水流、光扫、碎裂、烟雾）**仍然取消**，v2 的丰富是用**图表语言**的多样化，不是特效堆叠。

### 5.3 节奏规则

1. 平均 8–15 秒换一张卡，全片 12–18 张；一张卡讲 2–4 句。
2. 同一种卡**不连用**；每 3 张卡里至少 1 张「非拆解型」（折线 / 瀑布 / 天平 / 象限 / 条文）。
3. 第 5 秒内必须有第一个画面变化（数字滚动、条文划线、柱子长出）。
4. 一屏只有一个重点，一种强调色（橙）。

### 5.4 封面模板 v3（老杨样板）

- 版式：超大橙色粗体主标题（左对齐，≤3 行，最大 210px，自动缩到放得下）压在压暗的实景底图上；下面依次是英文副标、一句话摘要（≤2 行）、橙色药丸标签（期号 + 深度拆解）、底部品牌条。
- 全部内容在 3:4 裁切安全区（y240–1680）内，视频号 / 抖音竖封面不丢字。
- **主标题必须点出这期讨论什么**（封面规则 v2 继续有效：`cover.topic` 必填，标题里必须含它）；悬念、数字钩子放摘要。
- 字段：`title`（≤3 行，`<br>` 分行）、`topic`、`en`（英文副标）、`sub`（摘要 ≤2 行）、`tag`（药丸大字，默认取 `frame.ep`）、`tag2`、`chip`（左上小标，默认「老杨魔方 · 企业经营观察」）。
- 底图用正片同一张实景图，压暗由封面模板统一处理。

## 6. 出片流程（v2 增量）

1. 选题过测试（三支柱）→ 写 `decision`。
2. 七步写稿（沿用 v1 第 3 节）；**第 8 步**：写开场（§2，含 §2.6 感觉词）、结尾金句和决策清单（§3），填 `publish`。
3. `python3 core/lint_opening.py episodes/<期>` 自检；build 也会自动跑。
4. 其余同 v1：配音（默认 ×1.21）→ build → `render.py snap` 抽帧 → 发老杨确认文案 → Mac 出片机。
5. 出片检查：开场前两句不触发禁用、有感觉词和「你/老板」；`publish` 齐全；有决策清单卡；每 3 张卡有 1 张非拆解型；封面标题含 topic。
