## 1. 这条线是什么

竖版 1080×1920 / 30fps，标准版约 60–75 秒、深度版 3–5 分钟（§1.1）。老杨本人复刻音色（×1.2）旁白逐句讲一个经营判断，画面跟着**旁白里的词**动（词级锚点），底部有字幕。片子三层：

| 层 | 内容 | 每期改不改 |
|---|---|---|
| 外框（第 0 秒起常驻） | 底图慢推 + 遮罩 + 左上 logo（右侧文章标题）+ 核心观点头条 + 半透明底板 + 进度条 + 声波 + 字幕 + 底部署名 + 片尾粒子 logo | **不改**（core/shell.html） |
| 中间区动画 | canvas 线条/粒子/烟雾/光扫 + 卡片文字 + 核心观点文字效果 | 每期重写（scenes.html + scenes.js） |
| 声音 | 旁白 + 有旋律和鼓点的 BGM + ≤20 个采样音效 | 每期换（lines.json） |

### 1.1 两种规格（v2.2）

| | 标准版 | 深度版 |
|---|---|---|
| 时长 | 60–75 秒 | 3–5 分钟（约 900–1300 字） |
| 什么时候用 | 一个判断 + 两三个事实就讲得清 | 要靠一串数据把论证做实；观点要明确、可检验 |
| 章节 | 3–6 章 + 片尾 | 6–8 章；开场和提问章不上进度条，进度条仍 ≤6 项 |
| 数据 | 每个实数注来源 | 每个论证章至少一个一手数字；判断落成**可检验的标准**（「看三件事」） |
| 头条 | 每章 1–3 条 | 同左（全片约 15–18 条） |
| 配乐 | 一首 ≥ 片长的曲子 | 选有「安静段 → 全乐队回归」结构的长曲，回归点对齐「我的判断」（`bgmSection`） |

规格按内容深度定，不为凑时长加内容。范例：深度版《民企丢掉的公平》（3:18）。

叙事骨架：**钩子数字 → 背景事实（1–3 章）→ 现场变化 → 作者亲历观察 → 「我的判断」（收一拍后落下）→ 二选一提问 →（系列片）下期预告**。v2.1 起不再有「关注老杨魔方」。

头条规则：
1. 在 lines.json 写 `heads`：`[["c0","投1块，|只转回8毛1"], ["v02|先别|s","先别加钱，|先想去哪里"], …]`。键是章节 id（章节开始时切换）或锚点（说到那个词前 0.15s 切换）；`|` 手动换行。
2. **每章至少一条，最多三条**；第一条从第 0 秒就显示（也是首帧 / 封面感）。片尾章放全片收束的一句。
3. 头条写**观点**，不写章节名（「投入涨了十年」✗ →「投1块，只转回8毛1」✓）。
4. 不与同一时刻中间区的核心观点文字效果、卡片标签重复同一句话（头条说结论，中间区演过程）。
5. 切换动画由外壳负责：旧的上移淡出 0.25s，新的模糊浮现 0.35s。

## 3. 字号与颜色

- 字号层级（中间区）：眉标 36 橙 · 卡片标题 60 白 · 正文 ≥40 · 小标签 34 · 注释/来源/「示意」28 · 数字 96 · 核心观点 64–88 · 印章 56 · VS 72。**禁止巨大文字**（单字高度不超过 96px）。
- 颜色：橙 #F5A623（强调、线、进度）· 金 #F0B429（数字、事实高亮、光扫）· 绿 #3CF07A（新、正向、AI）· 象牙 #FFE9C4（中性线、粒子）· 灰 #8C857A（旧、失效、灰烬）· 红 #E8553A（只用于印章/转让这类一次性动作）。
- **同一时刻画面上只亮一种彩色**，其余用象牙/灰的低透明度；密度 = 亮度（粒子用叠加混合）。
- 字体：Noto Sans SC（OFL），build 时按全片用字自动子集化（含 scenes.js 里画布用的字）。
- 底图：全片一张实拍（Pexels 等可商用），竖屏原生裁切不放大；C 档调色偏暗暖；慢推（全片平移 14/26px、放大 3%→8%）。

## 4. lines.json 字段（每期的唯一配置）

| 字段 | 说明 |
|---|---|
| `series.title / sub` | 主标题 / 副标题（同时用于文件名） |
| `cover` | 封面眉标、大字（可 `<br>`）、副标 |
| `bg / bgUrl / bgNote` | 底图路径 / 下载地址 / 说明（底图不进仓库） |
| `voice` | v2.2 起默认 `{"engine":"volc-icl","resource":"seed-icl-2.0","tempo":1.2}`（老杨本人复刻音色，提速 ×1.2）；备选 Edge TTS `zh-CN-YunyangNeural` +25% |
| `gapSec / secGap` | 句间 0.3s，章节间 0.6s（吸附拍点） |
| `bgm` | file / url / src（出处与许可） |
| `beat` | BGM 测拍：bpm / period / t0（core/beatfit.py） |
| `restBefore` | 哪一句前「收一拍」：BGM 静音一拍、画面定格变暗，然后判断落下 |
| `bgmSection` | 让 restBefore 那句落在曲子的哪一秒（乐句线/高潮段） |
| `progress` | 进度条章节 `[["开场","c0"],...]`，3–6 个 |
| `transitions` | 章节入场转场 `{"c1":"smoke","c2":"sweep"}` |
| `endNext` | 可选，系列片片尾预告：`"下期讲：怎么去"`（冒号后橙色） |
| `heads` | **v2 必填**：核心观点头条 `[[章节id或锚点, "文字"]]`，规则见 §2.1 |
| `sfx` | 音效点 `[锚点, 种类, 偏移秒]`，≤20 个；音效的**冲击点**对齐锚点 |
| `sfxlib` | 音效库：file / url / hit / from-to / lvl（峰值窗相对人声 RMS 的 dB，−5~−15） |
| `lines.vNN` | `sec` 章节、`sub` 字幕原文、`tts` 读法（数字写汉字；行业/本行/投行写航业/本航/投航）、`screens` 手动分屏 |

**锚点** `T('v05|下降|s')`：v05 里「下降」开始（`s`）/结束（`e`）的时刻，可加偏移 `|+0.2`。按 tts 文本找词（数字要写读法）。build 自动扫描所有锚点，找不到直接报错。

## 5. 动画规矩

### 5.1 通用
- 每个关键词一个动作：数字→计数滚动；「下降」→折线下坠触底冲击；「注销」→点阵烟散；「换工具」→故障切片；「我的判断」→收一拍后冲击环落下。
- 线条用发光线 `gline`；旧的/失效的变灰再用 `smoke` / `disperse` 退场；新的用绿/金。
- **中间区不能空着超过 0.8 秒**（「收一拍」那一拍除外）：一句话的关键词还没到、上一组图形已经退场时，用挂在这句话前半段的轻画面接住（信号线、流向、重现上一章的图形、基线、阵型），不要等。出片前跑 `core/blankcheck.py` 自动查。
- 单屏一个焦点；中间区只放卡片层级文字和核心观点，不把旁白整句搬上去（字幕已经有了）。
- 三档速度：**漂**（4–8s 背景漂移）/ **推**（0.6–1.2s 讲述）/ **击**（0.12–0.25s 冲击，只在关键词上）。每章至少出现两档，制造快慢对比。
- 每个实数旁注来源（28px）；示意图形注「示意」；作者亲历注「作者观察 · 示意」。去人名公司名：「某专家」「某上市公司」。
- **引用他人观点**（框架、比喻、判断出自别人的文章）：画面注「观点参考：<公众号 / 机构名>」（不写个人姓名），发布文案写原文标题和出处。
- 片尾（v2.1）：**不出现「关注老杨魔方」**——配音不说、画面不写；系列片只放「下期讲：…」。底部常驻署名保留。（v1 期数的片尾粒子 logo 保持原样）

### 5.2 核心观点文字的出场 / 退场（v1.2 起为标准）

用 `showText(key, spec, t, 入场时刻, 退场时刻, 入场方式, 退场方式, a)`，写在 `SCENES.cN.free` 里。六种方式：

| 方式 | 入场 | 退场 | 性格 | 用在 | 建议配音效 |
|---|---|---|---|---|---|
| 粒子 | 粒子从四周飞拢聚成字（1.5s） | 吹散：风从左往右吹成粒子（1.4s） | 从无到有、聚少成多 | 数字、结论的诞生；「消失、被风吹走」 | 闪粉 whoosh（Mixkit #2350） |
| 雾化 | 雾中由模糊变清晰（1.7s） | 雾散：被雾一层层吞掉往上散（1.8s） | 含蓄、看不清 | 局势判断、回忆、不确定 | 柔风声 / 无 |
| 水流 | 波前流过显字，水面晃动的高光（1.7s） | 融化：像液体往下淌、拉长、滴落（1.7s） | 流动、渗透、流失 | 趋势、周期、「冲刷/流失/融化」 | 水流 swish |
| 光扫 | 一道金光扫过显影（1.0s） | 光扫抹去（0.9s） | 确认、权威 | 定论、官方数据 | 闪光 shimmer |
| 碎裂 | 碎片从四周飞拢 + 冲击环（0.6s） | 炸开下坠（1.2s） | 冲击、打破 | 注销、崩盘、失效 | 玻璃碎 / 重击（#759 / #2908） |
| 逐字 | 从宽字距和模糊里逐字落定（1.2s） | 逐字松开上飘（1.0s） | 克制、留白 | 提问、金句（默认款） | 无或轻 tick |

**使用规范**
1. **只给核心观点用**：每章最多 1 处，全片 3–6 处。普通标签、来源注、数字卡片仍用 DOM 卡片样式——这样核心观点才显得特别。
2. **一期只选 2–3 种**，按上表「性格」配内容；同一种效果不连续两章使用（逐字除外）。
3. **时机挂在配音上**：入场开始 = 该句开始前 0.2–0.3s；入场结束不晚于关键词出口；退场在下一句开始前做完。碎裂必须落在击拍（关键词或 BGM 重拍）上。**落地后至少停留 1 秒**：退场时间挂在下一句的某个关键词上（不是挂在下一句开头），同区域的卡片等文字退完再进（第一期教训：真配音比占位快，「破了」一落地就退场了）。
4. **慢效果放慢段**：雾化、水流、融化用在叙述慢、留白多的地方；节奏紧凑的段落用光扫、碎裂、逐字。
5. **入场和退场可以混搭**（例如粒子入场 + 雾散退场），但要讲得通：退场方式 = 这句话的「下场」（被吹走、散了、流失了、被抹去、被打碎、淡出）。
6. **一句话最多高亮一段**，颜色按第 3 节（事实金、新事物绿）。
7. **不与卡片文字叠在同一区域**：核心观点居中 cy 900–1100 时，同区域的 DOM 卡片先退场。
8. 雾化 / 水流 / 融化每帧有像素运算，单屏最多 2 行。

### 5.3 粒子世界（v1.1 实验 → 候选，见 EFFECTS.md）
- 一批粒子贯穿一章，阶段之间换「阵型」，转场 = 粒子流过去。范例：`episodes/_demo_c2_粒子世界`（订单之河 → 33.82% 脱落 → 90 张证书 → 烟散 → 留空）。
- **疏密曲线**：最重要的一句话配全片最空的画面；**密度可以直接编码数据**（脱落 33.82% 的粒子）。
- **时间变慢** `makeWarp`：关键数字落下时全场慢到 1/10。
- 粒子层写在 `SCENES.cN.free`，用 `present()` 羽化 + 辉光；该章用 `HOOKS.texA` 压低底纹点阵。
- 状态是「候选」：正式期使用前先在手机上检查压缩后是否糊。

## 6. 声音规矩

- 旁白（v2.2 起默认）：**老杨本人声音**，火山引擎声音复刻 2.0（seed-icl-2.0），**整体提速 ×1.2**（`voice.tempo: 1.2`，用户定为标准；原 1.15）。云端直接跑 `core/gen_vo_volc.py`（凭证在云环境变量 `VOLC_API_KEY` / `VOLC_SPEAKER_ID`，需放行 openspeech.bytedance.com），它会自动调 `core/align_chars.py` 提速并按字估时间。个人声音的 mp3 不进仓库（.gitignore 忽略 *.mp3），只提交 `vo/*.words.json`。
- 备选：Edge TTS 云扬 +25%（`core/gen_vo.py`）；whisper 抽查多音字。
- 数字一律在 `tts` 里写读法（「百分之五十点一」「二零二五年」）；复刻音色每句前后约 0.3s 静音，`gapSec` 用 0.15。
- BGM：有主旋律、鼓组、高潮段；比人声低 **7.9 dB**（`bgmUnder: 7.9`，v2.1 起；原 7 dB，用户要求再降 10%）；1.5s 淡入、2.5s 淡出；「我的判断」前一拍静音。
- 音效：Mixkit 采样，≤20 次，全部对齐画面动作；原始文件不进仓库，`core/fetch_assets.py` 下载。
- 总线：压缩（−22dB, 2.5:1）→ 增益 → 限幅 0.89，迭代到 **−14 LUFS**。

## 7. 制作流程（不可跳步）

1. **开工前**：读本文件、CHANGELOG 最近两版、BACKLOG 前几条、EFFECTS 里「标准」状态的效果（ITERATION.md §2）。
2. **内容**：核心观点一句话 + 按第 1 节骨架排结构；事实逐条核源写 FACTS.md，未核实的不用 → 等确认。
3. **文案**：逐句 v01…vNN（每句 ≤ 两屏字幕），标出章节、收一拍、核心观点句及其文字效果 → 等确认；确认后一字不改。
4. **制作**：
   ```
   cp -r starter episodes/<日期_主题>
   python3 core/fake_vo.py     episodes/<期>     # 离线占位配音，先排版
   python3 core/gen_vo_volc.py episodes/<期>     # 默认：老杨本人声音（云环境变量 VOLC_API_KEY / VOLC_SPEAKER_ID，放行 openspeech.bytedance.com），自动 ×1.2 提速 + 按字对齐
   python3 core/gen_vo.py      episodes/<期>     # 备选：Edge TTS 云扬（可只重配：... v02 v05）
   # 云端网络放行不了 Edge TTS 时：把 lines.json、gen_vo.py、fetch_assets.py、生成配音和素材.command 放进
   # 用户 Mac 的 materials/老杨魔方知识分享版/<编号-题目>/，请用户终端跑一次，再分小包回传
   ```
